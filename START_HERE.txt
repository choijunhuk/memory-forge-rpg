[이미지 담당 고정]

[Claude 자동 호출·구독 결제 절대 제한]
Codex가 같은 실행 환경에 로그인되어 있는 Claude Code CLI를 직접 실행·관리한다. claude --version과 claude auth status, 유효한 구독 인증, 초과 과금 비활성 상태를 먼저 확인한다. 모든 조건이 확인된 뒤에만 별도 worktree에서 claude -p를 읽기 전용으로 짧게 시험한다. Claude 앱을 사용자가 별도로 열어야 한다고 가정하지 마라. 인증되지 않았거나 실행 권한이 없다면 BLOCKED로 보고한다.
Claude Pro/Max 구독 사용량 **외의 모든 과금 경로는 금지**한다. ANTHROPIC_API_KEY / ANTHROPIC_AUTH_TOKEN / apiKeyHelper / 프록시·클라우드 제공자 인증이 우선하면 API로 호출하지 마라. API 키·토큰 값은 절대 읽거나 출력하지 말고 설정 존재 여부만 검사한다. 설정이 섞여 있으면 자식 프로세스 환경에서만 안전하게 분리하여 기존 구독 인증을 재검증하고, 청구 경로가 불명확하면 실행을 중단한다. 새 API 키, Console 크레딧, 종량제 사용, 별도 유료 이미지 서비스, 자동 충전·사용량 초과 결제는 어떠한 경우에도 사용하지 마라.
Claude 구독의 5시간/주간 한도 등에 걸리면 API 결제·추가 사용 크레딧으로 우회하지 않는다. Claude 쪽만 BLOCKED_SUBSCRIPTION_LIMIT으로 기록하고 현재 구독 내 독립적인 Codex 작업을 진행한다. 호출 결과와 기준 커밋/파일 diff를 저장하고, 이미지 생성 담당은 계속 Codex로 둔다.

[협업과 자율성]
GitHub는 비공개로 관리한다. 기존 원격 저장소와 작업 브랜치를 먼저 확인하고 재사용하며 임의 공개·강제 푸시·기존 작업 삭제를 하지 않는다. 원격이 없다면 인증된 계정과 사용 가능한 도구를 확인한 뒤 memory-forge-rpg 비공개 저장소 초기 구성을 진행하되, 권한 부족·동명 충돌은 보고한다. 초기 저장소 구성은 Codex가 한 번만 맡는다.
Claude와 서로 다른 worktree/브랜치를 사용하고 같은 파일·Unity 씬·프리팹을 동시에 수정하지 않는다. Unity MCP는 실제 연결된 도구와 프로젝트를 확인한 뒤 local/dev에서만 사용한다. Claude 호출이 실제로 성공했다고 검증되지 않으면 자동 협업이 연결됐다고 보고하지 마라. Claude는 Codex의 채팅을 자동 열람한다고 가정하지 마라. 변경 파일·커밋·검사·다음 요청을 인계 파일과 PR로 전달한다.
기존 기획을 축약하거나 시스템을 빼고 새 프로젝트로 만들지 마라. 합의된 범위의 구현·버그 수정·UI 세부·의상 변주는 자율적으로 진행한다. 가격·확률·재화 총량·캐릭터 나이·영구 자산의 의미·유료 서비스·실결제·운영 배포 변경만 따로 확인한다. 이미 명시된 목표 구현과 새로운 정책 제안을 구분한다.

## 2026-10-15 추가 사용자 지시 — 현재 실행 우선

충돌 시 이 절과 `docs/AI_WORKFLOW.md` §10이 기존 모델 역할표·배포판 시작 순서에 우선한다. **Codex는 `gpt-6.1-sol`만, Claude는 Opus(`claude-opus-5-5`)만** 사용한다. Astra·Fable·Luna·다른 모델·자동 fallback은 금지한다. 두 계정의 기존 5배 구독 포함 사용량만 쓰며 API/Console/구매 크레딧·추가 사용·자동 충전은 금지한다. 사용량 절약보다 품질을 우선한다.

기본 **High**, Codex의 핵심 전투·예약·카드/부품·기억·경제·인증·서버·이관·아키텍처·복잡한 버그·중요 계획·최종 검증과 Claude의 종합 계획·서사·캐릭터·최종 검토에는 **Max를 적극 사용**한다. Medium 이하를 관성적으로 선택하지 않고 담당 AI가 자율 결정한다. 실제 CLI·설정에서 지원·적용 여부를 확인하며 프롬프트 선언을 실행 증거로 세지 않는다. Claude Max는 지원되는 세션 CLI/환경 경로로 적용하고 미지원 영구 `modelSettings` 값으로 저장하지 않는다.

주요 작업 전에 요구사항 절·게임 내 역할·완료 조건·담당 파일을 기록하고 **개발 → 시험 → 반대편 AI 독립 검토 → 수정 → 재검증 → 통합 → 다음 작업**을 반복한다. 핵심 결함·명세 위반은 해결·재검토 전 통합하지 않는다. 두 차례 미해결이면 대안·근거·위험을 남기고 해당 항목만 보류한다. P1/P2 완료를 세션 종료 조건으로 삼지 않고 다음 로드맵 작업을 계속한다. 정책·권한·환경·한도 차단도 해당 작업만 보류하며 세션 밖 지속 작업을 약속하지 않는다.

Codex가 공식 Claude CLI를 별도 worktree에서 직접 호출·회수하며 실제 세션·모델·노력·종료·검증 증거를 남긴다. 재귀 호출은 금지한다. Unity MCP를 실제 Editor의 Scene·Prefab·UI·Animation·Console·Play 시험·임포트·빌드에 적극 사용하되 한 씬·프리팹 쓰기 담당을 지킨다. 설치만으로 연결을 주장하지 않고 유료 `asset_gen` 공급자는 사용하지 않는다. 이미지 생성·내용 수정은 Codex, Claude는 브리프·검수·비생성형 적용 담당을 유지한다.

설정과 실제 실행 증거는 `docs/AI_ENVIRONMENT.md`, 현재 개발 상태는 `docs/CURRENT.md`를 따른다. 기존 설계 v0.8.1·수치·승인 경계·비공개 원격·변경 이력은 보존하고 기능/시험 축소로 통과시키지 않는다. 자동 시험은 Unity Play·실기기 수용 증거와 구분한다.
