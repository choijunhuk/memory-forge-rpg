# 카드 흐름 연구 — 기억 공방 참고용 묶음

**게임 전체 패키지의 새 버전이 아닙니다.** 현재 개발 프로젝트를 그대로 두고, 이번 자료만 참고 경로에서 읽으세요.

- `START_CODEX_MESSAGE.txt`: 현재 Codex 채팅에 복사해 넣을 지시문.
- `card-flow-study/`: 사용자가 보낸 원본 파일 16개를 변경 없이 보존.
- `review/ADOPTION_REVIEW.md`: 채택·수정·보류와 현재 기억 공방에 적용할 경계.
- `review/original-tests.tap`: 이 환경에서 실행한 기존 시험 27/27 통과 기록.
- `review/demo.txt`: 헤드리스 가상 시계 데모 실행 기록.
- `review/independent-probes.ts`·`.json`: 추가 확인 3건의 재현 코드/관찰 결과.
- `review/typecheck-*.txt`: 타입 검사 최초 실패(환경 타입 의존성)와 보완 경로 통과 기록.
- `review/source_integrity.json`: 원본 ZIP 해시와 원본 16개 파일 동일성 대조.

원본 연구는 카제나 공개 자료 조사와 독자 설계를 구분합니다. 예제의 퓨즈/AP/입력 큐/연출 시간은 기억 공방에 자동 적용할 수치가 아닙니다. 기존 코드를 덮어쓰거나 별도 엔진을 런타임에 추가하지 마세요.

실제 반영은 현재 승인된 설계·코드에 맞춰 진행하며, 이미 구현된 항목은 재작성하지 않습니다. 작성자와 다른 AI의 교차 리뷰, Unity MCP 확인, 구독 전용·Codex 이미지 생성 담당 등 기존 협업 정책을 유지합니다.
