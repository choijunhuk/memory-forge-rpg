## 5.2 전투 구성

- 파티는 캐릭터 **3명**(1~3명 허용, 정식 콘텐츠는 3명). 체력은 **파티 공유 풀**(각 캐릭터 체력의 합)이다. 캐릭터 개별 사망은 없다.
- 덱 = 세 캐릭터의 기억 덱(저장 덱 또는 기본 덱: 시작 카드 4 + 공용 1) + 캐릭터별 장착 무기 카드 1장. 기본 덱 기준 18장.
- 적은 1~5체. 소환은 살아 있는 적이 5체 미만일 때만 된다.
- 전투 상태(`s`)는 직렬화 가능한 순수 JSON이다. 모든 무작위는 전투 시드로 초기화한 xoshiro128**(§5.15)에서만 뽑는다.

## 5.3 턴 진행 순서

**전투 시작(`begin`)**: ① 뽑을 더미 섞기 ② 전투 시작 효과(유물 `bronze_cog` 방어 8, `pocket_brazier` 무작위 적 화상 4, 무기 패시브 시작 방어, 공명 `battleStart` 효과 중 부품 부착 제외) ③ `eternal_seed`: 무작위 성장 카드 성장 +1 ④ 1턴 시작.

**턴 시작(`startTurn`)**:

1. 턴 번호 +1. 단계 = 해결 중.
2. 최초 1턴에는 전투 시작 효과로 얻은 방어·반격을 보존한다. 2턴부터 파티 방어를 0으로 정리하되 `bulwark` 수치까지 유지하고 반격은 0으로 한다. 기간이 끝난 버프는 정리한다.
3. 이번 턴 카운터 초기화: 낸 카드 수, 직전 카드 주인, 이번 턴 카드 주인 목록, 계약 수, 비용 0 횟수, 다음 카드 보너스, 잔향(= 시작 잔향), 임시 예약 칸, 턴 플래그, 균열 행동력 보너스 횟수, 캐릭터별 이번 턴 게이지, 카드별 이번 턴 비용 변경.
4. 행동력 = 4 + 이월 보너스(균열·카드·사건) (+1 `chrono_crown`, 첫 턴 −1 `cracked_hourglass`) − **이번 턴 만기 부채**, 0~9로 자름. 만기 부채는 제거.
5. `infinite_circuit`: 파티 체력 −2(쓰러지면 전투 종료).
6. **만기 예약 해결**: 만기 턴 ≤ 현재 턴인 예약을 (만기 턴, 건 순서) 순으로 하나씩 해결. 도중에 전투가 끝나면 남은 예약 카드는 버린 더미로.
7. 턴 시작 파워(`rebirth` 회복).
8. **뽑기**: 5 − 드로우 페널티(절제 위약) (+2 `quick_hands`·무기 첫 태엽: 첫 턴만). 이어서 이번 턴 만기인 메아리 사본을 손에 생성. 첫 턴에는 `memory_anvil`(증폭 2장)·공명 부품 부착 효과.
9. 적 의도 확정(§5.7). 단계 = 플레이어.

**플레이어 단계**: 카드 사용(§5.4), 필살기(§5.10), 턴 종료.

**턴 종료(`endTurn`)**:

1. 절제 계약이 활성이고 이번 턴 낸 카드가 3장 이하면 다음 턴 보너스(첫 예약 +30%) 확정. 아니면 지난 보너스 만료.
2. 손에 남은 **얼룩** 1장당 파티 체력 −2. 손패를 모두 버린 더미로.
3. 파티 약화 −1.
4. **적 단계**: 살아 있는 적을 등장 순서대로. 각 적은 행동 직전에 자기 방어와 반사를 0으로 한다. 균열(행동 불가) 상태면 행동을 건너뛰고 패턴만 한 칸 진행. 아니면 이번 의도를 실행하고 패턴 한 칸 진행. 매 공격 후 파티가 쓰러지면 즉시 종료.
5. **라운드 종료**: 적 화상 피해(화상 수치, 방어 무시) 후 화상 −1 → 씨앗 회복 → 적의 취약·약화·표식 −1 → 균열 만료 확인(균열이 걸린 다음 턴의 라운드 종료에 게이지를 최대로 회복).
6. 다음 턴 시작.

## 5.4 카드 사용

### 사용 방식

| 카드 `res` | 허용 방식 | 표기 |
|---|---|---|
| `y`(기본) | 지금 · 다음 턴 예약 · 다다음 턴 예약 | (없음) |
| `n` | 지금만 | [즉시 전용] |
| `o` | 다음 턴 · 다다음 턴 예약만 | [예약 전용] |
| `after` | 다다음 턴 예약만 | [다다음 턴 예약 전용] |
| 키워드 `contract` | 지금만 | [계약] |
| 부품 `noReserve`(즉발 회로) | `y`/`n` 카드를 지금만 | — |

### 비용

`비용 = 카드 비용 + 이번 턴 비용 변경 + 부품 비용(경량 회로 −1) + 조건부 비용(costIf) − 1(빈 시계: 전투 첫 예약 1회)`. "다음 n장 비용 0"(`freeNext`)이 남아 있으면 0. 최소 0.

### 사전 검사(`precheck`, 상태를 바꾸지 않음)

다음 순서로 검사하고 처음 실패한 코드로 거절한다. 거절된 명령은 **아무것도 바꾸지 않는다**.

1. 플레이어 단계인가 → `WRONG_PHASE`
2. 방식이 now/next/after인가 → `INVALID_MODE`
3. 손에 있는가 → `NOT_IN_HAND`
4. 허용 방식인가 → `RESERVE_ONLY`(지금 불가) / `NOT_RESERVABLE`(예약 불가)
5. 행동력 ≥ 비용 → `AP_LOW`
6. 대상: 피해 효과가 있으면 대상이 필요하다. 살아 있는 적이 1체면 자동 지정. 대상이 없거나 죽었으면 `BAD_TARGET`. **고정 대상** 효과가 있으면 대상에 표식이 있어야 한다 → `FIXED_MARK_REQUIRED`
7. 효과별 검사: 선불(부채 상한 `DEBT_CAP`, 행동력 9 초과 `LOAN_OVERFLOW`), 유예(다음 턴 만기 부채 없음 `NOT_DEFERRABLE`), 절제(이번 턴 이미 3장 이상 냈거나 이번 턴 이미 절제 계약을 맺음 `RESTRAINT_UNAVAILABLE`), 담보(이미 봉인 중이거나 다음 턴 빈 칸 없음 `NO_EMPTY_SLOT`), 앞당김(예약 없음 `RESERVATION_REQUIRED`, 옮길 다음 턴 칸 없음 `PULL_DESTINATION_FULL`), 과부하(쓰러짐 `OVERLOAD_WOULD_KILL`)
8. 예약이면 그 턴 칸이 남았는가 → `SLOT_FULL`

UI는 같은 검사(`check(uid, mode, target)`)로 버튼을 비활성화하고 이유를 보여 준다.

### 확정(`commit`)

행동력 차감 → 비용 0 횟수 −1 → (예약이면) 빈 시계 사용 처리 → 손에서 제거 → 이번 턴 낸 카드 +1 → **잔향 처리**(리엔 편성 시, 직전 카드 주인과 다른 캐릭터의 카드면 잔향 +1, 공용 카드는 건너뜀) → 계약 수 +1 → 절제 활성 중 4장째면 위약(다음 턴 드로우 −1) → 지금이면 즉시 해결, 예약이면 예약 장부에 등록.

### 해결(`resolveCard`)

1. 고정 대상 카드: 대상이 죽었거나 표식이 없으면 **불발**(비용 환급 없음, 카드는 버린 더미/소멸 규칙 그대로).
2. 일반 예약 공격: 대상이 죽었으면 살아 있는 첫 번째 적으로 대상 변경.
3. 절제 보너스: 보너스 턴의 첫 **예약** 피해/방어 카드에 +30%(가산 그룹).
4. 리엔 듀엣(`nextBoost`): 즉시 사용한 다른 캐릭터 카드 1장에 보너스.
5. 소유 캐릭터 필살기 게이지 +10(§5.10).
6. 효과 목록을 순서대로 실행. 실행 도중 전투가 끝나면 즉시 멈춘다(뒤의 회복 등은 실행하지 않음).
7. 부품 후처리(보호 방어, 회수 뽑기, 가속 게이지, 메아리 사본) → 성장 카드 해결 처리(유리 패시브·온실·무기) → 세라 공명 1.
8. 사용 횟수 +1 → 소멸 키워드·소멸 부품·전투당 사용 횟수 소진이면 소멸 더미, 아니면 버린 더미.

## 5.5 시간 예약

- 예약은 `{카드, 대상, 만기 턴(절대값), 건 순서, 종류(next/after)}`로 저장한다. 다음 턴 예약의 만기 = 현재 턴 + 1, 다다음 턴 = + 2.
- **칸 계산**: 다음 턴 칸 = min(3, 기본 2 + 이번 턴 임시) − (봉인 중이면 1). 다다음 턴 칸 = min(2, 기본 1 + 이번 턴 임시). 사용 중인 칸 = 그 만기 턴에 걸린 예약 수. 따라서 지난 턴에 다다음 턴으로 건 예약은 이번 턴의 **다음 턴 칸**을 차지한다.
- **값 선택**: 다음 턴 예약으로 해결되면 `rv`, 다다음 턴이면 `ra`(없으면 `rv`, 그것도 없으면 `v`). 상태 수치는 `rn`.
- **봉인**(담보 계약): 다음 턴 칸 1개를 다음 내 턴 종료까지 막는다(그 턴과 다음 턴 모두 다음 턴 칸 −1). 빈 칸이 있어야 봉인할 수 있다.
- **앞당김**(시간 당기기): 고른 예약(없으면 가장 먼저 건 다다음 턴 예약, 없으면 가장 먼저 건 예약)을 1턴 앞당긴다. 다다음 → 다음이 되면 다음 턴 칸이 비어 있어야 한다. 다음 턴 예약을 당기면 **즉시 해결**한다(값은 원래 종류 기준). 다다음 턴 예약을 다음 턴으로 당기면 종류가 `next`로 바뀌어 `rv` 값을 쓰고, `ra`와 다다음 전용 보너스(원거리 전송 +70%)는 잃는다.
- **전투 종료 시** 남은 예약 카드는 버린 더미로 돌아간다(카드 보존 불변식).

## 5.6 균열과 속성

- 속성: 전격·화염·빙결·공허·무속성. 캐릭터 카드는 캐릭터 속성, 무기 카드는 장착자 속성, 공용 카드는 무속성.
- 적은 균열 게이지(최대값 `brk`)와 약점 속성 1~4개를 가진다.
- 피해를 줄 때마다 게이지 감소 = (공격 속성이 약점이면 카드의 균열 수치(기본 1) + 부품·유물 보너스) + 충격 수치(속성 무관).
- 게이지가 0이 되면 **균열**: 그 적의 다음 행동 1회 취소(의도가 "균열: 행동 불가"로 바뀜), **받는 피해 +25%**(다음 플레이어 턴 끝까지), **파티 다음 턴 행동력 +1**(턴당 최대 +2). 균열 중에는 게이지가 줄지 않는다.
- 균열은 걸린 턴의 다음 턴 라운드 종료에 풀리고 게이지가 최대로 돌아온다.
- 설계 의도: 예약 공격을 "균열이 걸린 다음 턴 시작"에 터지게 걸면 +25%를 온전히 받는다. 세라의 선견(+25%)은 이 타이밍의 보상이다.

## 5.7 적 의도와 행동

- 적은 **고정 패턴을 순환**한다(무작위 없음). 화면에는 **이번 행동과 다음 행동**이 항상 보인다. 균열 중이면 이번 행동 = "행동 불가", 다음 행동은 그대로 보인다.
- 적 공격 피해 = round(기본 피해 × 난이도 피해 배율 / 100) + 힘 → 적이 약화면 ×0.75(내림) → 파티 방어로 먼저 막고 남은 만큼 체력 손실 → 반격이 있으면 그 적에게 반격 피해(반격 2배 버프면 2배).

| 행동 `t` | 효과 |
|---|---|
| `atk` | 피해 d를 h회 |
| `atkdebuff` | 피해 후 파티 상태(약화 n) |
| `def` | 자신 방어 b(+힘) — 방어는 **자기 다음 행동 직전까지** 유지 |
| `buff` | 힘 +n(지속) |
| `debuff` | 파티 약화 n |
| `charge` | 아무것도 하지 않음(다음 행동이 강공임을 알림) |
| `summon` | 소환물 n체(적 5체 상한) |
| `heal` | 체력 비율이 가장 낮은 적 회복 n |
| `insert` | 버린 더미에 저주 카드 n장 |
| `reflect` | 반사 n: 카드 피해를 받을 때마다 파티가 n 피해(방어 먼저). 자기 다음 행동 직전에 사라짐 |
| `expose` | 자신 취약 +n 후 이어진 공격 실행 |
| `blockAll` | 모든 적 방어 +b |

| `counter` | 반격 | 파티 | 적의 공격 1회마다 공격한 적에게 반격 수치만큼 피해. 플레이어 턴 시작 시 0. |
| `charge` | 충전 | 파티 | 다음 피해 카드 1장의 피해 +n%. 사용하거나 기간이 끝나면 사라짐. |
| `reflect` | 반사 | 적 | 카드 피해를 받을 때마다 파티가 반사 수치만큼 피해. 적 행동 시작 시 사라짐. |

| 키워드 | 규칙 |
|---|---|
| 소멸 | 사용 후 이번 전투에서 제외(소멸 더미). |
| 계약 | 즉시 사용 전용. 부채·봉인 등 미래 비용이 있다. |
| 전투당 n회 | n회 사용하면 소멸. |
| 예약 | 비용을 지금 내고 다음 턴(또는 다다음 턴) 시작에 해결. 예약 수치가 따로 적힌 카드는 그 수치를 쓴다. |
| 예약 전용 | 즉시 사용할 수 없다. |
| 다다음 턴 전용 | 다다음 턴 예약만 가능. |
| 고정 대상 | 표식이 있는 적만 지정 가능. 해결 시 대상이 죽었거나 표식이 없으면 불발(비용 환급 없음). |
| 성장 | 예약으로 해결될 때 성장 +1(카드당 전투 1회, 파티 전투당 3회). 성장 3이면 전투 보상 화면에서 진화 분기 선택. |
| 과부하 n | 사용 시 파티 체력 n을 잃는다(방어 무시). |
| 충격 n | 속성과 관계없이 적의 균열 게이지를 n 깎는다. |

## 5.9 방어·반격·체력

- 파티 방어는 2턴 이후 턴 시작에 0이 된다(보루 파워 예외). 최초 턴에는 시작 효과의 방어를 유지한다. 적 방어는 그 적의 다음 행동 직전에 0이 된다.
- 반격은 2턴 이후 턴 시작에 0이 되고, 그 턴 동안 쌓인 반격이 적 단계에서 공격 1회마다 그 적에게 발동한다(적 방어가 먼저 막음, 균열 게이지는 줄지 않음). 화상·유물 피해도 균열 게이지를 줄이지 않는다(화상은 방어 무시).
- 회복은 최대 체력을 넘지 않는다. 회복량은 방어와 같은 체력 배율(§5.12)과 스킬 배율을 받는다. 넘친 회복은 에일라 패시브(50%)·카드 효과(`overflowBlock`)가 있을 때만 방어로 바뀐다. `memory_anvil` 유물이 있으면 휴식 회복 불가.
- 체력 0이 되면 패배. 단, `memory_envelope`(탐사당 1회)는 체력 1로 버틴다.

## 5.10 필살기 게이지

- 캐릭터마다 0~100. 자기 카드(무기 카드 포함)가 **해결될 때마다 +10**(지금·예약 모두), **턴당 +30까지**. 공용 카드는 게이지를 주지 않는다.
- 턴 상한(30)은 **카드 해결 기본 +10에만** 적용한다. 효과로 얻는 게이지 — 카드·필살기의 `gauge` 효과(예: 공용 카드 사기 진작 전원 +15), 부품 가속(+10), 유물 `time_stamp`(예약 해결 +5) — 는 상한을 무시한다.
- 100이면 필살기 사용 가능(행동력 0, 손패와 무관, 턴 중 언제나). 사용 시 게이지 −100. 필살기는 카드가 아니므로 잔향·낸 카드 수에 포함하지 않는다.
- 필살기의 피해·방어·회복은 필살기 레벨(§11) 배율을 받는다(카드는 카드 스킬 레벨).

## 5.12 피해·방어 수식

모든 계산은 정수/BigInt로 하고 **마지막에 한 번만 내림**한다.

```text
기본값 B = 카드 값(지금 v / 다음 턴 rv / 다다음 턴 ra) + 카운터 비례(scale, 최대값 적용) + 고정 가산(전격 코일 +4 등)
피해 = floor( B
        × power4 / 160                       ; 전투력(캐릭터·무기 카드는 소유자, 공용 카드는 파티 power4 평균을 반올림)
        × (1 + 0.04 × (스킬 레벨 − 1))         ; 고유 카드 = 카드 스킬 레벨, 필살기 = 필살기 레벨
        × (1 + 가산 그룹 합 / 10000)            ; 아래 표, 음수 가능(최소 0)
        × 1.25 (대상 취약) × 1.25 (대상 균열) × 0.75 (파티 약화)
        × 조건부 배수(mult) )
방어 = floor( B × 체력/81 × 스킬 배율 × (1 + 방어 가산 합/10000) )   ; 체력 = 카드 주인 캐릭터 체력, 주인 없으면 파티 평균(반올림)
회복 = floor( B × 체력/81 × 스킬 배율 ) → 기도문 등 회복 버프 → 무기 은빛 선율
```

**고정 수치의 배율 규칙(레벨이 달라도 기준 전투와 같은 체감).** 공격 쪽 = 전투력(power4/160): 카드 피해, 반격·화상·유물 고정 피해(파티 평균). 방어 쪽 = 체력(체력/81): 카드 방어·회복, 유물·부품·패시브의 고정 방어와 회복, 과부하·유물의 체력 대가(파티 평균). 적 쪽 = 스테이지 피해 %: 적 공격, 반사, 얼룩 손실. 기준 전투(전투력 160·체력 81·배율 100%)에서는 모든 배율이 1이다.

**가산 그룹**(모두 더한 뒤 한 번에 곱함): 부품(증폭 +30%, 과열 +50%, 지연 증폭 예약 +40%/즉시 −10%, 즉발 +20%, 원거리 전송 다다음 +70%, 경량 −25%, 소멸 대가 +50%), 니아 손재주(+15%, 개조 카드), 설계도 파워, 황금 깃펜(+15%, 개조 카드), 유리 공명 4(진화 카드 +15%), 무기 패시브(예약·표식·저체력·균열·첫 공격·기본 무기 정련), 균형 감각(부채), **장신구**, 절제 보너스(+30%), 리엔 듀엣, 충전(정조준 등, 다음 공격 카드 1장), 세라 선견·미래 확정·공명 6, 라비엔 신용, 시온 망각의 서가, 루미 임계 질주·한계 돌파, 사건 파일 파워, 불씨 반지(화상 적 +10%), 신용 장부(+20%).

### 계산 예시 (엔진 실측값)

| 예 | 조건 | 계산 | 결과 |
|---|---|---|---|
| A1 | 세라 「유리탄」 지금, 기준 전투 | 8 | **8** |

## 5.13 손패·더미

- 뽑기: 뽑을 더미가 비면 버린 더미를 섞어 뽑을 더미로 만든다(둘 다 비면 중단). 손패가 10장이면 뽑은 카드는 버린 더미로(“넘침”).
- 생성 카드(드론 사격 등)와 메아리 사본은 **토큰**: 전투가 끝나면 사라지고 저장 대상이 아니다.
- 메아리 회로 사본은 원본 예약이 해결된 **다음 턴 시작, 뽑기 직후**에 손에 생성된다(그 전에는 카드가 존재하지 않아 섞여 들어가지 않음). 비용은 평생 0(`free`), 위력 50%, 사용 후 소멸. 손패가 가득하면 버린 더미로 간다. 복제(탈피) 토큰도 평생 비용 0.
- 저주: 얼룩(턴 종료 시 손에 있으면 체력 −2, 사용 시 소멸), 위약금(비용 2, 사용 시 소멸).

## 5.14 종료

- 모든 적 사망 → 승리. 파티 체력 0 → 패배. 판정은 효과 하나가 끝날 때마다 한다(다단 히트 중간 포함).
- 종료 시 남은 예약 → 버린 더미, 부채·절제·보너스 소멸. 결과 `{phase, turn, hp}` 기록.

## 5.15 명령·결정론·공개 정보

- 전투는 **명령**으로만 바뀐다: `begin`, `play {uid, mode, target, picks}`, `ult {actor, target}`, `end`.
- 명령 요청 = `{rid(요청 ID), v(기대 버전), kind, args}`. 처리: 같은 rid가 저장돼 있으면 내용 해시가 같을 때 저장된 응답을 그대로 돌려주고, 다르면 `IDEMPOTENCY_CONFLICT`. 버전이 다르면 `STALE_VERSION`. 상태 사본에서 실행 → 불변식 검사 → 성공 시에만 교체(원자성).
- **불변식**(`checkInvariants`, 매 명령 후): 파티 체력 0~최대, 행동력 0~9, 손패 ≤ 상한, 부채 ≤ 상한, 파티 성장 횟수 ≤ 전투 상한, 모든 카드가 정확히 한 곳(뽑을·손·버린·소멸·예약)에만 있음, 게이지 0~100, 적 체력·방어·균열 ≥ 0, 만기 턴별 예약 수 ≤ 칸 상한(3/2).
- RNG: xoshiro128**(splitmix32 시드). 전투·탐사 시드는 서버가 정하고 클라이언트에 보내지 않는다. **모집은 이 RNG를 쓰지 않는다**(서버 CSPRNG, §12).
- 공개 상태(`publicView`): 뽑을 더미는 장수만(순서 비공개), 적은 이번·다음 의도. 적의 고정 패턴은 도감에 공개하는 정보라 숨기지 않는다. **숨기는 것은 RNG 상태·뽑을 더미 순서·무작위 대상/보상 결과**이며 서버 비공개 상태에만 둔다.

## 5.16 첫 턴 경계의 회귀 기준

> **출처·상태:** v0.7.1 검토서 5쪽을 이 장에 통합. 아래 재현 수치는 해당 검토의 기록이며, 이번 재실행 결과는 §19.1 및 reports/audit_v081에서 별도로 확인한다. 목표·제안은 실행 완료가 아니다.

원본 `begin()`은 청동 톱니, 무기 패시브, 하린 공명의 시작 효과를 먼저 처리한다. 바로 뒤의 `startTurn(true)`가 방어와 반격을 지워, 지급 직후 효과가 사라졌다. 원본 설명 자체도 시작 지급과 무조건 초기화를 연달아 나열해 모순의 원인이 되었다. [O §5.3, p.11; R §2.1; T repro_original.json]

| 재현 장착 | 부여 값 |
|---|---:|
| 청동 톱니 | 방어 8 |
| 장부 자물쇠 R5 | 방어 8 |
| 하린 공명 4 | 방어 10 |
| 하린의 관련 반격 효과 | 반격 2 |
| 원본 begin() 직후 | **방어 0 / 반격 0** |
| 수정본 begin() 직후 | **방어 26 / 반격 2** |

#### 채택한 규칙
**최초 턴은 이전 플레이어 턴이 없으므로 시작 보상을 정리하지 않는다.** 2턴부터는 기존 방어 정리와 보루 유지 수치를 그대로 적용한다. 단순히 방어 초기화 전체를 삭제하면 무한 누적이라는 다른 게임이 된다.

#### 추가한 검증
첫 턴 지급 보존, 두 번째 턴 정상 초기화, 보루 수치만 유지하는 경로를 각각 검사했다. 전투 시작용 성장 유물로 받은 방어도 같은 경계를 통과한다.

#### 이식 요구
C#에 같은 `first` 의미를 옮기고, 시작 이벤트와 일반 턴 시작 이벤트를 구분한 트레이스를 만든다. 첫 턴만 통과하는 숫자 시험이 아니라 2턴까지 비교해야 한다. 현재 C#에는 전투 전체 구현이 없으므로 이번 수정이 C# 전투에 반영됐다고 말하지 않는다.

## 5.17 진화 카드의 성장 계열 판정

> **출처·상태:** v0.7.1 검토서 6쪽을 이 장에 통합. 아래 재현 수치는 해당 검토의 기록이며, 이번 재실행 결과는 §19.1 및 reports/audit_v081에서 별도로 확인한다. 목표·제안은 실행 완료가 아니다.

원본에서 진화 카드 자체에는 `growth:true`가 없고, 원본 카드 ID는 `from`에 남는다. 일부 해결 후 콜백은 이미 `from`을 확인했지만, 성장치 합·성장 카드 수·손패 조건은 기본 카드의 `growth`만 보았다. 따라서 “모든 패시브가 아예 호출되지 않는다”는 외부 설명은 과장이고, **효과별 판정 불일치**가 정확한 진단이다. [O §5.11, §6.3, §9.3 유리; R §2.2]

| 개념 | 기본 성장 카드 | 유효하게 진화한 카드 |
|---|---|---|
| 성장 계열인가 | 예 | 예 |
| 유효 성장치 | 실제 0~3 | 3 |
| 다시 성장할 수 있나 | 3 미만이면 가능 | 아니오 |
| 온실·성장 해결 패시브 | 적용 | 적용 |
| 읽었다는 이유로 이끼 발동 | 아니오 | 아니오 |

수정본은 `growthRoot / isGrowthInst / effGrowth`를 분리했다. `from` 문자열만 믿지 않고 **원본의 진화 목록에 현재 ID가 있는지** 확인한다. 임의 카드에 유리 카드의 `from`을 붙여 계열 보너스를 얻지 못하게 한다.

#### 재현 결과
진화 3장의 성장 카드 수는 0→3, 성장치 합은 0→9가 되었다. 유리 고치: 수호를 즉시 사용하면 기본 방어 9에 공생 결속 6이 더해져 15가 된다.

#### 복제까지 확인
탈피와 메아리 사본에 `from`을 전달해 진화 계보가 끊기지 않게 했다. 비용 0 플래그는 그대로 유지한다. 저장 시 토큰 제외 규칙도 바꾸지 않았다. 토큰을 포함한 계열 카운터의 세부 밸런스는 원본 설계에 맞춘 현재 구현이며, 실제 전투 재미 검증과는 별개다.

## 5.18 성장 이벤트와 공생 이끼

> **출처·상태:** v0.7.1 검토서 7쪽을 이 장에 통합. 아래 재현 수치는 해당 검토의 기록이며, 이번 재실행 결과는 §19.1 및 reports/audit_v081에서 별도로 확인한다. 목표·제안은 실행 완료가 아니다.

공생 이끼의 문장은 “성장이 일어날 때마다 방어 3”이다. 원본에서는 예약 성장·일부 선택 성장만 이끼를 호출하고 `growLowest`, `growAll`, `eternal_seed`는 직접 성장치만 올렸다. [O §7.8, p.27; R §2.2; T]

#### 수정 구조
`applyGrowth(카드, 양, 출처/상한 옵션)`에서 성장 가능 여부, 0~3 범위, 횟수 제한, 실제 증가, 이벤트, 이끼 방어를 한 번에 처리한다. 효과별 상한은 통일하지 않는다. 원래 상한과 별개인 필살기·씨앗은 그 의미를 유지한다.

| 상황 | 성장 처리 | 이끼 |
|---|---|---|
| 예약 카드, 일반 상한 미만 | 실제 +1 / 개체당 1회 | 방어 3 |
| 같은 개체 예약 재해결 | 추가 성장 없음 | 없음 |
| 이미 성장 3 | 변화 없음 | 없음 |
| 진화 카드 로드 | 유효 성장 3으로 해석 | 없음 |
| growLowest로 두 장 +1 | 실제 두 이벤트 | 방어 6 |
| 이후 growAll로 두 장 +1 | 실제 두 이벤트 | 방어 6 |
| 영원의 씨앗 +1 | 시작 이벤트 1회 | 방어 3 |

필살기의 원래 방어 12 + 성장 네 번의 방어 12 = **24**를 재현했다. 외부 문서는 씨앗도 고친다고 적었으나 제공한 코드 블록에는 씨앗 수정이 빠져 있었다. v0.7.1 패키지는 해당 경로와 1턴 방어 보존을 함께 시험했다.

#### 추가 안전장치
성장치가 음수·비정수·3 초과인 상태는 불변식 검사에서 거절한다. 성장량 +2가 한 번 적용될 때 ‘성장 이벤트 1회’인지 +1 두 번인지 구별한다. 현재 공생 이끼는 성공한 카드 성장 처리 1회당 한 번이며, 이 해석은 새 효과를 만들 때도 문서화해야 한다.
