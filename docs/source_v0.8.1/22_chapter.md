# <a id="ch22"></a>22. 남은 결정과 위험

## 22.1 미확정 결정

| 항목 | 현재 | 제안·다음 단계 |
|---|---|---|
| 모집 | 50:50·다음SSR 확정·최대160; 수급96회 최대 | 확률·수급 변경 없음. §12.8의 배너별 지급 조건으로 비교 |
| 저장 | legacy 기본 덱 재구성 | §8.8~8.14 보존형 목표를 실제 Run/HTML/서버에 연결 |
| 용량 | 공명4 포함 최대9 | 무료 승급으로 최대9; 상태 이관 후 전환 |
| 균열 | 6층 모두 2팀 기획, 진행기 없음 | 1~3층1팀·4~6층2팀 목표 |
| 결말 | 전원 조각20 기획 | 본편6인장/동료조각20 분리 목표 |
| 캐릭터 나이 | 데이터의16~28세 | 성인20~24세 중심 대안은 승인 전, 숫자·연혁·표현 동시 조정 |
| 아트 | 실제 자산 없음 | 10명 보완 브리프·프롬프트50개로 시안 제작 |
| 보통 난도(D2) | 현행 수치 | 적 피해+10% 대안은 미채택. 사람 플레이 결과로 결정 |
| 화면 방향(D5) | Unity 가로 고정 | 웹 시제품 세로 대응은 별도이며 세로 게임 추가는 미결정 |

| 음성(D7) | 한국어 우선 | 일본어 추가는 비용·제작 범위 검토 후 결정 |

## 22.2 위험

| 위험 | 영향 | 대응 |
|---|---|---|
| 예약·균열 규칙이 초보자에게 어렵다 | 이탈 | 온보딩 4단계(§14.5), 버튼 미리보기, P0-1 이해도 측정 |
| 반천장으로 무과금 체감 악화 | 평판·이탈 | §12.6 손잡이, 확률·기대값 투명 공개 |
| 10명 × 자산 묶음 제작량 | 일정 | 이미지 생성 + 사람 리터치 파이프라인, 캐릭터 묶음 단위 일정(§13.5) |
| 10대 캐릭터 표현 검수 누락 | 스토어·평판 | §9.1 규칙, §15.5 체크리스트, 생성 프롬프트 안전 블록 고정 |
| C# 이식 불일치 | 판정 오류 | 상태 해시 교차 시험(§16.2) 없이는 서버 판정에 쓰지 않음 |
| 결제·모집 동시성 | 금전 사고 | 단일 트랜잭션·고정 잠금 순서·영수증·원장, 동시성 시험 |
| 무료 재화 과다/과소 | 수익·체감 | 시즌마다 원장 기반 실측 → ADR로만 조정 |
| AI 생성 자산 권리 | 법적·스토어 | provenance 기록, 사람 리터치 원본, 도구 약관 확인 |
