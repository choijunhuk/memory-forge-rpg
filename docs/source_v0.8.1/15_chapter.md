# <a id="ch15"></a>15. 아트·연출·사운드

## 15.1 아트 디렉션

- 키워드: **밤의 공방, 황동 계기, 멈춘 시계, 번지는 잉크, 기억의 빛(청록)**. 배경은 어둡고 차분하게, 캐릭터와 카드 테두리(속성색)가 가장 밝게.
- 캐릭터 화풍: 한국 서브컬처 모바일 게임의 셀 셰이딩 + 부드러운 회화 조명, 선명한 선. 실사·3D 렌더 질감은 쓰지 않는다.
- 실루엣: 10명이 검은 실루엣만으로 구분돼야 한다(세라 롱코트+장총, 니아 공구 건틀릿+드론, 유리 지팡이 등불, 라비엔 저울 펜던트, 하린 대형 방패, 리엔 바이올린+트윈테일, 에일라 종 등불+땋은 머리, 시온 책갈피 장검+긴 흑발, 카야 탐정 모자+석궁, 루미 쌍단검+짧은 뻗친 머리).
- 속성색은 이펙트·카드 테두리·약점 아이콘에만 강하게 쓴다(§14.2 토큰).
- 적: 잉크·종이·황동 부품이 뭉친 형체. 사람 얼굴을 직접 그리지 않는다(공포 수위 15세 이내).

## 15.2 통합 아트 기준

§9.1의 공통 기준과 §9.3의 캐릭터별 보완 브리프를 사용한다. 노출 유무 하나로 반려하지 않고 표정·행동·실루엣·동료 관계의 매력을 함께 검수한다. 기본 시트의 정적인 정면 자세를 액션 키아트까지 강제하지 않는다. 현재 연령 데이터는 유지하며 대안 연령은 자동 적용하지 않는다.

## 15.4 이미지 생성 운영 (기본: Codex의 이미지 생성, 선택: 로컬 모델)

1. **참조 고정**: 캐릭터마다 [SHEET] 프롬프트로 디자인 시트를 먼저 확정한다. 이후 모든 생성은 확정 시트를 참조 이미지로 넣고, 같은 핵심 키워드(외형·의상·무기·팔레트)를 그대로 반복한다.
2. **생성 → 선별 → 수정 → 사람 리터치**: 한 장면당 4~8장 생성 → 기준 체크리스트(§15.5)로 선별 → 부분 수정(인페인팅) → 아티스트가 손·무기·의상 디테일·선 정리. 최종 자산은 사람이 손본 레이어 PSD를 원본으로 보관한다.
3. **기록**: 자산마다 프롬프트·참조 이미지·도구/모델 이름·날짜·수정자를 `art/provenance.csv`에 남긴다(저작권·재현성·스토어 문의 대응).
4. **제작 기준:** §9.1 공통 기준을 적용한다. 시트·키아트·카드·SD의 목적을 구분하고 안전 기준을 일상복·비성적 교감·역동적인 행동 전체의 금지로 확대하지 않는다. 실제 심사 등급은 생성 프롬프트 문구로 보장하지 않는다.
5. **스타일 일관성**: 공통 STYLE 문장을 바꾸지 않는다. 바꿀 때는 아트 디렉터 승인 후 모든 캐릭터 시트를 재확정한다.

## 15.5 아트 검수

| 검사 | 통과 조건 |
|---|---|
| 캐릭터 정합성 | 얼굴·키·머리·눈·무기·모티프가 기준 시트와 일치한다. |
| 개성 | 10명의 실루엣과 표정·행동이 구별되고, 전투 능력과 일상 습관이 연결된다. |
| 장면 적합성 | 기본 시트는 중립, 키아트는 동적, SD는 읽기 쉬운 비성적 표현으로 목적을 구분한다. |
| 의상 | 자연스러운 일상·계절복을 일괄 배제하지 않고 §9.1의 공통 표현 기준을 적용한다. |
| 품질 | 손가락·무기·의상 연결·글자 오류를 검사하고 실제 게임 크기에서 식별한다. |
| 기록 | `art/provenance.csv`에 도구·프롬프트·참조·수정·자산 버전을 남긴다. |

## 15.6 캐릭터별 제작 프롬프트 50개

10명 × SHEET/KEYART/CUTIN/SD/EXPR의 5종이다. 다음 블록은 본편 데이터의 현재 나이를 사용하고, 새로운 동작·의상 대안은 보완 브리프에서 가져온 **제작 초안**이다. 최종 이미지나 리그가 아니다. NEGATIVE는 품질 항목이며 핵심 표현 기준은 §9.1과 함께 적용한다. JSON 원본은 `art/briefs/prompts_v0.8.1.json`.
