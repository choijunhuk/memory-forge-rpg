# <a id="ch0"></a>기억 공방 / Memory Forge — v0.8.1 복구·검증 통합 설계서

**문서 버전 0.8.1 / 실행 규칙 데이터 0.7.0 / 기준 JS: v0.7.1 수정 참조.** 날짜: 2026-10-14.

이 문서는 v0.8의 편집 누락을 복구한 전체 설계 기준서다. 원본 23개 장, 10명 전투 시트와 고유 카드, 효과 DSL·부품·유물·사건, 이미지 프롬프트를 다시 연결하고 검토 보완을 해당 장에 배치했다. 원본을 요약본으로 대체하지 않았다.

## 0.1 먼저 볼 결론

| 구분 | 확인 결과 |
|---|---|
| 표시된 오류 | 존재하지 않는 임시 경로의 package.json 읽기가 실패했다. 그 읽기 실패만으로 최종 산출물의 손상 여부는 판정할 수 없다. |
| 실제 v0.8 문제 | ZIP은 열리지만 통합 본문에 세계관·전투·카드·탐사와 세라·시온 상세 누락이 있었다. 원본 파일은 ZIP 안에 남아 복구 가능했다. |
| 이번 수정 범위 | 문서 본문·목차·생성 경로·검사·인계 안내·매니페스트 복구. 실행 엔진·밸런스·가챠·가격·성장 데이터는 변경하지 않았다. |
| 현재 플레이 가능 | JS 규칙 참조와 브라우저 시제품. 저장은 현행 legacy 정책이다. |

| 아직 없는 제품 | Unity 클라이언트, C# Battle/Run 전체 이식, 서버 애플리케이션, 후반 구역의 완성 플레이, 실제 아트·음성·결제. |

## 0.2 문서·데이터의 권위와 변경 범위

**설계 목표**와 **현행 실행 참조**를 별도 계층으로 읽는다. `content/*.mjs`와 `data/game_data.json`은 지금 실행되는 수치이며, 미구현 목표를 자동 반영하지 않는다. 목표와 현행 코드가 다르면 아래 명시된 작업으로 이식하고 검증한다.

1. 사용자의 명시적 결정과 기록된 변경 범위.
2. `docs/decisions_v0.8.1.md`의 복구·상태 결정. 과거 ADR는 `docs/decisions.md`에 이력으로 보존.
3. 이 문서의 **현행** / **목표** / **비교안** 표기.
4. 현행 수치: `content/*.mjs` → `data/game_data.json`; 동작: `engine/rules-core.js`.
5. 현재 제작 브리프: §9.3 각 캐릭터 보완 블록, §15 프롬프트. 원본 나이와 젊은 성인 대안은 구분.

현재 통합 원본은 `docs/source_v0.8.1/00_*.md`부터 `23_*.md`까지다. `docs/design_v0.8.1.md`와 PDF는 생성물이다. 원본 장의 HTML 앵커 `ch0`~`ch23`로만 경계를 읽는다. 캐릭터 1~10 번호를 장 번호로 취급하지 않는다.

## 0.3 재현과 인계

`docs/START_CODEX.md` 또는 `docs/START_CLAUDE.md`로 시작한다. `npm run docs`는 이 버전 통합 문서를 다시 만든다. 구판 `gen_docs.mjs`는 옛 참조 데이터 표 생성용이며 최신 PDF를 대체하지 않는다. 상세 명령·해시·보존표는 `reports/audit_v081`.

본문 23개 장의 목차는 PDF의 클릭 가능한 목차·책갈피를 사용한다. 표의 수치는 사업성·사람 플레이 테스트로 확정한 값이 아니다.

## 0.4 확인한 것과 확인하지 않은 것

이번 JS 시험 51개, Python 경제 시험 23개, 독립 저장 모듈 14개를 재실행했다. 짧은 탐사 100회·정규 40회의 퍼즈도 실행했다. 이것은 해당 참조 구현의 검사이지 운영 제품 인증이 아니다. PDF/ZIP/문서 내용 검사는 별도로 실행한다.

C#·DB·실기기·실결제에 대한 과거 로그는 이번 실행 증거로 합산하지 않는다. 브라우저는 파일 URL 로딩이 환경 정책에 의해 막혔으며, 인라인 실행과 실제 배포·저장 원점 검증을 구별한다. 최종 상태표와 명령별 로그는 §19.1을 따른다.

## 0.5 표기 규칙

확률은 bps(1 bps = 0.01%)로 저장한다. 기준 전투는 전투력 40(power4 160), 캐릭터 체력 81, 스킬 Lv.1이다. 다음/다다음 턴은 현재 턴 +1/+2이며 예약에는 절대 만기 턴을 저장한다. 카드 ID와 개체 키를 구분한다.
