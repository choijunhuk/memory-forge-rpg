## 23.7 오류의 의미와 검증 근거

`FileNotFoundError`는 지정한 경로의 파일·디렉터리를 찾지 못했다는 뜻이다. 공개된 traceback의 해당 읽기는 실패했다. 이 로그만으로 이후 생성 실패·성공을 단정할 수 없으므로 최종 ZIP CRC, PDF 전체 페이지 파싱, 본문 비교, 파일 해시와 직접 실행으로 판정했다. 원본 v0.8 PDF와 ZIP 안 PDF는 같은 해시였고 ZIP은 정상 열렸지만 본문 누락이 확인됐다.

Python 공식 설명: https://docs.python.org/3.13/library/exceptions.html#FileNotFoundError 및 https://docs.python.org/3.13/library/pathlib.html#pathlib.Path.read_text (2026-10-14 확인). 프로젝트 결함은 웹이 아니라 첨부 파일 비교와 실행 로그로 확인했다.
