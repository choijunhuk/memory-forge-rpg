# <a id="ch7"></a>7. 탐사(로그라이트)

`engine/rules-core.js`의 `Run`과 대응한다.

## 7.1 탐사 생성

| 입력 | 설명 |
|---|---|
| `party` | 3명: `{charId, res(공명), weaponId, refine, level, asc, weaponLevel, armor, accessory, skillLv, ultLv}`. 서버는 소유 데이터에서 직접 만든다(클라이언트 값 불신) |
| `memory` | 캐릭터별 저장 덱(없으면 기본 덱) |
| `zones` | 방문할 구역 순서. 짧게 `[1]`, 정규 `[1,2]`, 스토리 장은 장마다 지정(§11.8) |
| `bosses` | 구역별 고정 보스(스토리). 없으면 구역 보스 목록에서 무작위 |
| `stageLevel` | 적 배율 기준 레벨(§11.1). 없으면 기준 전투(100%) |
| `difficulty` | 보통 `{hp:100, dmg:100}`, 어려움 `{hp:120, dmg:125}`. 스테이지 배율과 곱한다 |
| `seed` | 서버가 정한다 |

시작 상태: 동전 60, 파티 체력 = 캐릭터 체력 합(기준 전투 81×3 = 243), 덱 = 저장 덱(또는 기본 덱) + 무기 카드 3장.

## 7.2 지도 생성(구역마다)

- 7층 + 보스. 0층 노드 3개, 나머지 층 2~3개(무작위).
- 노드 종류:

| 층 | 규칙 |
|---|---|
| 0, 2 | 항상 전투 |
| 1 | 전투(첫 노드만 1/3 확률로 사건) |
| 3 | 전투 30 · 엘리트 20 · 사건 20 · 휴식 15 · 공방 15(%). 이 층에 휴식/공방이 하나도 없으면 첫 노드를 휴식으로 |
| 4 | 전투 60 · 엘리트 40 |
| 5 | 전투 30 · 엘리트 15 · 사건 20 · 상점 20 · 공방 15 |
| 6 | 휴식 · 공방 · 상점(노드 순서대로) |
| 보스 | 6층의 모든 노드와 연결 |

- 엘리트는 지도 전체 최대 2개, 한 경로에서 연속 엘리트 금지(자식 엘리트는 전투로 바뀜).
- 연결: 각 노드는 다음 층의 비례 위치 노드와 연결하고, 1/2 확률로 오른쪽, 아니면 1/3 확률로 왼쪽 노드와도 연결. 부모가 없는 노드는 같은 위치의 부모와 연결.
- **보장**: 모든 경로에서 보스 전 전투(일반+엘리트) 3회 이상(0·2·4층). 시험: `engine/tests/engine.test.mjs`의 300개 시드 검사.

## 7.3 노드

| 노드 | 내용 |
|---|---|
| 전투 | 구역 일반 조우표에서 무작위 1개 |
| 엘리트 | 구역 엘리트 조우표. 보상에 유물 1개 |
| 휴식 | 1회(공방의 불씨 유물 2회): 최대 체력 30% 회복(낡은 나침반 +10%p) 또는 카드 1장 강화 |
| 공방 | 1회(불씨 2회): **변주**(카드 1장 선택 → 무작위 영구 부품 3개 중 1개 부착) 또는 카드 1장 제거(무기 카드 불가) |
| 상점 | 카드 3(기본 45·고급 70·희귀 110 동전), 부품 2(일반 60·희귀 90), 유물 2(서로 다른 일반·희귀, 120·180), 카드 제거 1회(50 + 이번 탐사에서 **상점** 제거를 한 횟수 × 25) |
| 사건 | 8종 중 무작위(§7.7). 선택지에 조건(동전)이 있으면 부족 시 비활성 |
| 보스 | 구역 보스(스토리는 고정). 보상: 동전 100, 희귀 카드 3택 1, 보스 유물 3택 1 |

## 7.4 전투 보상

- **동전**: 일반 22~32, 엘리트 50~65, 보스 100 (+행운의 동전 10, 탐정 수첩: 표식 적 처치마다 +10).
- **카드 3택 1**(왕관 유물이면 2택): 각 칸 희귀도 판정 — 보스 S 100%, 엘리트 A 55 / S 45, 일반 B 58 / A 34 / S 8(%). 각 칸은 파티 중 1명의 고유 카드에서, 마지막 칸은 1/3 확률로 공용 카드. **공정성 규칙**: 지금까지 캐릭터별 제시 횟수 차이가 2를 넘으면 첫 칸은 가장 적게 제시된 캐릭터. 같은 보상 안에서 중복 없음.
- 받지 않기: 동전 +15(거절의 미덕: 최대 체력 +2, 탐사당 4회).
- **부품**: 일반 전투 25% 확률로 영구 부품 1개(가져가기 선택).
- **진화**: 성장 3에 도달한 성장 카드마다 진화 분기 2개 중 1개 선택(건너뛸 수 있음, 다음 보상 때 다시 제시).

## 7.5 구역 사이(기록소)

정규 탐사·여러 구역 장에서 보스를 이기면 기록소 화면: **귀환하고 저장**(정상 종료, 기억 저장) 또는 **계속**(최대 체력 15% 회복 후 다음 구역 지도). 계속한 뒤 패배하면 패배 저장 규칙(1개)을 따른다.

## 7.9 난이도와 배율

- 보통: 적 체력·피해 100%. 어려움: 체력 120%, 피해 125%.
- 스토리·이벤트·성장 던전·주간 보스·기록 균열은 **스테이지 레벨 배율**(§11.1)을 함께 곱한다. 적 체력 = round(기본 × 배율/100), 적 피해 = round(기본 × 배율/100) + 힘.
- 밸런스 목표(기준 전투, 시작 덱, 무작위/탐욕/계획 봇): §19.4.

## 7.10 패배와 이전 자산의 관계

현재 Run의 §7.6 결과는 §8.1~8.7 legacy 저장으로 이어진다. 제품 목표는 §8.8~8.14 보존형 저장이다. 앱 종료·네트워크 끊김 자체를 패배로 보지 않는다. 별도 상시 스토리 하드 메뉴는 추가하지 않으며 자유 탐사의 어려움은 선택 난도다.
