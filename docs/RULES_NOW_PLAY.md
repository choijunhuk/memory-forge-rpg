# 즉시 사용·보존 규칙 (2026-10-19 사용자 결정)

## 결정

사용자 지시(2026-10-19):

> 예약하는 느낌이 아니라 그냥 쓰게 하자. 카드 효과에 보존 같은 게 달려 있지 않으면 패 버려지고, 그냥 일반적인 카제나·슬더슬처럼.

함께 받은 방향:

> 슬더슬 게임에 서브컬처 스킨을 입힌 게임이 아니라, 서브컬처 게임인데 카제나처럼 슬더슬 요소가 있는 게임.

이 문서는 설계서 §2.2 기둥 1(「시간을 설계하는 전투」), §5.4 사용 방식, §5.5 시간 예약을 대신한다. 설계서 원문은 이력으로 보존하고, 실행 규칙은 이 문서를 따른다.

## 1. 규칙

1. **카드는 지금만 쓴다.** 모든 카드의 허용 방식은 `now` 하나다. `next`·`after` 방식, 예약 칸, 예약 장부, 만기 해결, 봉인, 앞당김은 플레이어가 만들 수 없다. 엔진의 예약 코드는 2단계에서 지운다.
2. **턴 종료 시 손패를 버린다.** 기존과 같다. 단, **보존** 카드는 손에 남는다.
   - 보존 카드: 키워드 `retain`이 있거나, 부품 효과 `retain`이 붙은 카드다.
   - 손에 남은 카드는 그 인스턴스에 `held = true`가 된다(보존했던 카드).
   - `held`는 그 카드가 손을 떠날 때(사용·버림·소멸) `false`가 된다.
   - 얼룩 페널티(턴 종료 시 손에 있으면 체력 −2)는 그대로다.
3. **해결 문맥의 `held`.** 카드를 쓰는 순간의 `held` 값을 해결 문맥(`ctx.held`)에 담는다. 아래 "예약으로 해결되면" 조건은 모두 `ctx.held`로 바뀐다.
4. **성장.** `grow` 연산은 예약 해결 때가 아니라 **카드가 해결될 때마다** 성장 +1을 준다. 카드당 전투 1회, 파티 전투당 상한은 그대로다. 앞선 피해로 전투에서 이기면 남은 효과는 멈추지만 `grow`는 적용한다.

## 2. 예약에 묶여 있던 규칙의 새 의미

| 대상 | 이전 | 새 의미 |
|---|---|---|
| 카드 수치 `rv`·`ra`·`rn` | 예약으로 해결될 때의 값 | 데이터에서 지운다. 늘 `v`·`n`을 쓴다 |
| 카드 문구 `[예약 전용]`·`[다다음 턴 예약 전용]`·`[즉시 전용]` | 사용 방식 표기 | 지운다. `보존` 키워드는 표기한다 |
| 조건 `reserved` | 예약으로 해결되면 | `held`: 보존했던 카드면 |
| 절제 계약 보너스 | 보너스 턴의 첫 **예약** 피해·방어 카드 +30% | 보너스 턴의 첫 피해·방어 카드 +30% |
| 리엔 듀엣(`nextBoost`) | 즉시 사용한 카드만 | 모든 카드 |
| 담보 계약(`collateral`) | 다음 턴 칸 봉인 + 방어 v | 방어 v + **부채 1**(다음 턴 만기). 검사는 `DEBT_CAP` |
| 세라 선견(`sera_foresight`) | 세라의 예약 공격이 균열 적에게 +25% | 세라의 **카드** 공격이 균열 적에게 +25%(필살기 제외, v0.8.1과 같음) |
| 세라 버프 `seraLock`(미래 확정) | 세라의 예약 공격 +n% | 세라의 카드 공격 +n% |
| 세라 공명 r1 | 유리탄이 예약으로 해결되면 1장 뽑기(턴당 1회) | 유리탄을 쓰면 1장 뽑기(턴당 1회) |
| 세라 공명 r6 | 필살기 다음 턴 시작에 해결되는 예약 공격 +50% | 필살기를 쓴 다음 턴, 세라의 카드 공격 +50%(그 턴이 끝날 때 끝남) |
| 세라 필살기의 「다음 턴 예약 칸 +1」 | 칸 추가 | 카드 1장 뽑기 |
| 무기 패시브 `w_reservedDmg` | 장착자의 예약 공격 +v% | 장착자가 **보존했던** 카드로 공격하면 +v% |
| 유물 빈 시계(`empty_clock`) | 전투 첫 예약 카드 비용 −1 | 전투 첫 카드 비용 −1 |
| 유물 타임 스탬프(`time_stamp`) | 예약 카드 해결 시 게이지 +5 | 보존했던 카드를 쓰면 소유자 게이지 +5 |
| 유물 정밀 렌즈(`precision_lens`) | 예약 공격 균열 +1 | 보존했던 공격 카드의 균열 +1 |
| 유물 금 간 모래시계(`cracked_hourglass`) | 다다음 턴 칸 +1, 첫 턴 행동력 −1 | 첫 턴 카드 2장 더 뽑기, 첫 턴 행동력 −1 |
| 유물 쌍둥이 시계추(`twin_pendulum`) | 다음 턴 칸 +1, 손패 최대 9 | 턴 시작 뽑기 +1, 손패 최대 9 |
| 유물 무한 회로(`infinite_circuit`) | 다음 턴 칸 +1, 턴 시작 체력 −2 | 턴 시작 뽑기 +1, 턴 시작 체력 −2 |
| 부품 지연 증폭(`c_delay`) | 예약 +40%, 즉시 −10% | **보존**을 붙인다(`retain`) |
| 부품 즉발 회로(`c_quick`) | 즉시 +20%, 예약 불가 | 피해·방어 +20% |
| 부품 메아리 회로(`c_echo`) | 예약 해결 시 다음 턴 50% 사본 | 해결 시 다음 턴 50% 사본(사본에는 회로가 없다) |
| 부품 원거리 전송(`c_far`) | 다다음 턴 예약 +70% | 피해·방어 +40%, 비용 +1 |

## 3. 카드 재설계

| 카드 | 이전 | 새 카드 |
|---|---|---|
| 세라 시한 포격(`sera_timed`, 2) | 예약 전용, 피해 16/22/30, 균열 3 | **보존**, 피해 20, 균열 3 |
| 세라 종언의 초침(`sera_last`, 3) | 다다음 턴 전용, 피해 45, 균열 5, 소멸 | **보존**, 피해 45, 균열 5, 소멸 |
| 세라 탄도 계산(`sera_calc`, 1) | 다음 턴 칸 +1, 1장 뽑기 | 다음 공격 피해 +30%, 1장 뽑기 |
| 세라 시간 당기기(`sera_pull`, 0) | 예약 1개 앞당김 | 버린 카드 1장을 손으로 |
| 세라 무기 카드 조준경 고정(`wc_sera`, 1) | 다음 턴 칸 +1, 다음 공격 +30% | 다음 공격 +30%, 1장 뽑기 |
| 공용 시간 닻(`com_anchor`, 1) | 다다음 턴 칸 +1, 1장 뽑기 | 2장 뽑기 |
| 공용 시간 축전기(`com_capacitor`, 1) | 예약 전용, 행동력 +2 | **보존**, 행동력 +2 |
| 공용 경계 사격(`com_overwatch`, 1) | 예약 전용, 피해 11, 충격 1 | 피해 9, 충격 1 |

## 4. 키워드

- 추가: `retain` 보존 — "턴이 끝나도 손에 남는다."
- 삭제: `reserve`, `reserveOnly`, `afterOnly`
- 변경: `growth` 성장 — "해결될 때 성장 +1(카드당 전투 1회, 파티 전투당 3회). 성장 3이면 전투 보상 화면에서 진화 분기 선택."

## 5. 화면

- 시간표(예약 레일)와 사용 방식 버튼(지금·다음 턴·다다음 턴)을 지운다.
- 카드는 적이나 무대에 끌어 놓거나, 눌러서 확정해 쓴다.
- 보존 카드는 카드에 「보존」 표시를 하고, 보존했던 카드는 빛나는 테두리로 구분한다.

## 6. 범위 밖 (2단계)

- 엔진의 죽은 예약 코드 삭제: `res` 장부, 칸 계산, `pull`·`slot` 연산, 예약 미리보기.
- 균형 재조정: 예약 값이 빠지며 플레이어 화력이 줄었다. `balance_probe`의 결과를 보고 따로 맞춘다.
