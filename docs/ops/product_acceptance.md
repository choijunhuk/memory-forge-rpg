# 제품 단계 인수 시험 — §19.3 현황 (2026-10-18 기준)

원문: [§19.3](../source_v0.8.1/19_chapter.md). 원문 표의 시험을 하나씩 나눠 현재 증거와 빈 곳을 적는다. 날짜가 다른 보고서는 그 실행의 증거이며 이번에 다시 실행한 것이 아니다. 관련 증거가 있어도 원문 시험과 범위가 다르면 통과로 세지 않는다.

상태 값: `통과`(원문 시험 그대로 통과), `부분`(일부 범위만 통과), `미구현`(대상 기능이나 시험이 없음), `미측정`(기능은 있으나 측정이 없음).

## 다음에 풀 수 있는 순서 (의존성 기준)

1. 개발 서버 범위에서 바로 할 수 있는 것: 전투 명령 왕복·서버 처리 시간 측정 도구(로컬 p95), Unity 최악 정보량 고정 장면과 겹침 판정.
2. 모집·구매 API가 생긴 뒤: 100병렬 이중 차감, 구매 토큰 재사용 거절, 100만 회 분포·카이제곱, 공개 표 해시 일치.
3. 기기 확보 뒤: 중급기 60fps, 글자 130% 실기기 판정.

가격·확률·재화 값은 이 문서에서 정하지 않는다. 확률 시험의 기대값은 승인된 데이터에서 읽는다.
