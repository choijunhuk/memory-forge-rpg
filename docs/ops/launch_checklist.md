# 출시 요건 점검표 — §18.4 (2026-10-18 기준)

원문: [§18.4](../source_v0.8.1/18_chapter.md). 원문이 말하듯 API 36·16KB·등급·환불 문장은 작성 당시의 제출 조건 가정이다. **이 표는 법령·스토어 심사 확인서가 아니다.** 실제 제출 때는 그날의 Play Console과 아래 공식 출처에서 계정·국가별 조건을 다시 확인한다. 출처 URL은 원문 [§23.5](../source_v0.8.1/23_chapter.md)에 있다.

상태 값:

| 값 | 뜻 |
|---|---|
| `확인됨(충족)` | 오늘 실제 증거로 요건을 만족함을 봤다 |
| `확인됨(미충족)` | 오늘 실제 증거로 요건을 만족하지 않음을 봤다(출시 차단) |
| `진행 중` | 다른 세션·작업이 고치는 중이다 |
| `미확인` | 증거가 없다. 확인 방법 열을 따른다 |
| `결정 대기` | 정책·승인 결정이 먼저다. 이 문서에서 정하지 않는다 |

## Android

| 항목 | 상태 | 근거 | 확인 방법 |
|---|---|---|---|
| 실기기 설치·실행·터치 | 확인됨(충족, 개발 빌드) | [Android 실기기 점검](../../reports/android_device_20261017/README.md) §4: SM-S928N(Android 16)에 dev APK 설치, 기동 595ms, 지도→전투 탭, Unity 예외 0 | 출시 후보 AAB로 다시 확인한다. 중급기(§16.4 Snapdragon 7 계열·RAM 6GB)에서도 확인한다 |
| 제출일 대상 API | 미확인(적용 요건) — 관찰값 35는 원문 가정 36에 못 미침 | 같은 보고서: dev APK는 compile/target **35**, min 23이다. 설치된 SDK Platform은 33/34/35다. `ProjectSettings.asset`의 `AndroidTargetSdkVersion: 0`(자동 = 설치된 최고값)이다. 원문 §16.4는 2026-08-31 이후 신규 앱·업데이트에 **API 36 이상**을 가정한다. 다만 §18.4가 말하듯 이것은 작성 당시 가정이고 제출일 요구치는 아직 확인하지 않았다. 가정이 맞다면 출시 차단이다 | Play Console 도움말 "대상 API 수준 요구사항"(§23.5)에서 제출일 요구치를 확인한다. SDK Platform 36을 설치해 target 36으로 빌드하고 실기기에서 다시 실행한다 |
| 64비트 | 확인됨(충족, 개발 빌드) / 설정 위험 | 같은 보고서: IL2CPP, `native-code: 'arm64-v8a'`. 그러나 프로젝트 설정 `AndroidTargetArchitectures: 1`은 ARMv7이다. ARM64는 빌드 스크립트(`MemoryForgeAndroidBuild.BuildDevApk`)가 메모리 안에서만 지정한다 | 출시 빌드 경로도 ARM64를 지정하는지 확인한다. AAB의 `lib/` 아래에 `arm64-v8a`가 있는지 본다 |
| 16KB 페이지 크기 | 진행 중(현재 미충족) | 같은 보고서: Android 16 기기에서 16KB 비호환 경고가 떴다. `lib_burst_generated.so`만 LOAD 정렬 0x1000(4KB)이고 나머지 라이브러리는 0x4000이다. `zipalign -P 16` 검사는 통과했다. 별도 세션(android-16kb)이 고치는 중이다 | 모든 `.so`의 LOAD 정렬이 0x4000 이상인지 본다(`llvm-objdump -p`, Android 문서 "Support 16 KB page sizes" §23.5). 16KB 기기·에뮬레이터에서 경고가 없는지 본다 |
| AAB·서명 | 미확인(미구현) | 만든 것은 dev APK뿐이다. `AndroidKeystoreName`이 비어 있고 출시 키·Play 앱 서명 등록이 없다. 패키지 `com.memoryforge.rpg.dev`는 빌드 스크립트 안에서만 쓰는 개발용 이름이다 | AAB 빌드, 업로드 키 보관 절차, Play 앱 서명 등록. 키는 AI 에이전트에게 주지 않는다(§18.1) |
| 포함 SDK 호환성 | 미확인 | 클라이언트에 결제·인증·분석 SDK가 아직 없다. Unity 6000.0.46f1 내장 라이브러리만 확인했다 | 출시 후보에 들어가는 SDK 목록을 만들고 각각의 16KB·target API·Data safety 신고 항목을 확인한다 |
| 첫 설치 크기 150MB 이하(§16.4) | 미확인 | dev APK 45MB이지만 AAB가 아니고 최종 아트가 없다 | 출시 후보 AAB의 Play Console 다운로드 크기 |
| PC(macOS) 빌드 | 확인됨(충족, 참고) | [PC 플레이 수용](../../reports/pc_playthrough_20261017/README.md): StandaloneOSX 빌드, 오류·경고 0, 실행 확인 | 스토어 요건은 아니다. 개발 확인용이다 |

## 요약

- 오늘 확인된 출시 차단: **16KB 정렬**(진행 중).
- 차단 가능성이 큰 미확인: **target API** — 관찰값은 35이고 원문 가정은 36 이상이다. 제출일 요구치를 공식 출처로 확인해야 확정된다.
- 확인된 정상: 실기기 실행(개발 빌드), ARM64(개발 빌드), macOS 빌드.
- 그 밖의 결제·등급·확률·개인정보·결제 보호·권리 항목은 미확인이거나 결정 대기다. 원문 §20 P6에 따라 이 체크리스트 전부를 사람이 승인해야 출시할 수 있다.
