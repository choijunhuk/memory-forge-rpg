#### 세라 — 미래는 읽어도 상대의 반응은 가끔 놓치는 시간 저격수.

**매력의 순서:** 차분함과 건조한 장난. 냉정한 표정만 반복하지 않는다.

**의상·실루엣:** 검정 바디수트와 열린 남색 코트. 황동 장식과 호박색 클립이 얼굴·조준경을 연결한다. 휴일에는 민소매 니트와 경쾌한 스커트 또는 팬츠로 대비한다.

**포즈·키아트:** 조준경을 내리고 상대와 눈을 맞추는 순간. 액션에서는 총과 몸의 대각선으로 사격 방향을 읽게 한다.

**성격의 반전:** 틀린 예측은 메모에서 몰래 지우지만, 동료가 좋아하는 음료는 직접 기억한다.

**로비 움직임:** 시계 확인 → 조준경 내리기 → 작은 미소. 전투와 로비의 온도 차를 만든다.

**새 대사 초안:** “3초 뒤에 웃을 거예요. …이번엔 맞았네.” / “미래를 봐도 오늘 커피 취향까지 맞히긴 어렵네요.”

**스킨 방향:** 「시계탑의 휴일」. 기본복과 다른 실루엣·생활 맥락을 먼저 검증한다. 변경 범위는 구매 전 로비·전투·대표 카드·궁극기·음성 항목별로 표시한다.

**제작 확인:** 얼굴에서 개성이 읽히는가, 행동이 직업·전투 방식과 연결되는가, 사복과 기본복이 구별되는가, 동료와의 관계가 한 장면에서 드러나는가. 이 브리프는 최종 일러스트나 음성의 완성이 아니다.


#### 니아 — 자기 드론에게도 말싸움을 거는 실력파 개조가.

**매력의 순서:** 장난기와 기술적 자신감. 나이가 어리다는 이유로 무능하거나 유아적인 말투로 만들지 않는다.

**의상·실루엣:** 짧은 작업 재킷 또는 허리에 묶은 재킷, 그래픽 티, 카고 반바지, 공구 벨트. 청록·보라 포인트가 공구와 머리핀에 반복된다.

**포즈·키아트:** 손바닥 위로 드론을 띄우며 성공을 자랑하는 전신. 도구를 돌리고 앞으로 내딛는 동적인 액션.

**성격의 반전:** 남의 장비는 쉽게 고치지만 자신의 실패작에는 이름표를 붙이고 버리지 못한다.

**로비 움직임:** 드론과 하이파이브 → 박자 놓친 드론 → 웃으며 다시 손 내밀기.

**새 대사 초안:** “새 기능 이름은 공방장이 지어줘요. 개조기 2호는 빼고요!” / “망가진 게 아니라, 다음 버전으로 넘어갈 준비 중이에요.”

#### 유리 — 사람 앞에서는 수줍지만 작은 생명을 지킬 때는 먼저 나서는 연구자.

**매력의 순서:** 투명한 색감과 조용한 고집. 늘 보호받는 역할 대신 발견과 해결을 직접 맡긴다.

**의상·실루엣:** 민소매 여름 원피스, 열린 가벼운 가운 또는 짧은 식물 재킷. 유리 문양은 소품과 그래픽에 쓰고 실제 의상 소재는 불투명하게 구성한다.

**포즈·키아트:** 등불 안의 새싹을 발견하고 고개를 드는 순간. 전투에서는 등불을 앞세워 동료를 보호한다.

**성격의 반전:** 평소 조용하지만 표본의 이름을 틀리면 정확한 이름을 끝까지 설명한다.

**로비 움직임:** 새싹 관찰 → 손을 흔들어 반응 확인 → 동료에게 발견 보여주기.

**새 대사 초안:** “첫 꽃은 같이 보기로 했잖아요. 오늘은 늦으면 안 돼요.” / “작아도 자리를 내줄 필요는 없어요. 이 아이도, 저도요.”

#### 라비엔 — 계산은 빠르지만 사람과의 약속만큼은 손해를 감수하는 협상가.

**매력의 순서:** 능청스러움과 영리함. 성인 팬서비스와 사람다운 허술함을 함께 둔다.

**의상·실루엣:** 와인색 비대칭 베스트, 트임 스커트, 장갑. 셔츠와 짧은 재킷을 사용하는 다른 실루엣도 제시한다. 성인용 이브닝 스킨은 기본복과 뚜렷이 구분한다.

**포즈·키아트:** 계약서를 뒤집어 숨은 조항을 보여주는 손동작과 눈웃음. 저울·인장 효과가 원형 시선을 만든다.

**성격의 반전:** 협상에서는 여유롭지만 개인 선물을 고를 때는 오래 망설인다.

**로비 움직임:** 도장 찍기 → 계약서 끝 돌리기 → 장난스러운 눈맞춤.

**새 대사 초안:** “오늘은 이자 대신 같이 걸어줘요. 꽤 후한 조건이죠?” / “계약에 없는 호의도 있어요. 이건 장부에 쓰지 않을게요.”

#### 하린 — 방패는 잘 들지만 칭찬 앞에서는 방어하지 못하는 전위.

**매력의 순서:** 멋있음과 서툰 배려. 상사보다 또래 팀의 든든한 동료라는 인상을 준다.

**의상·실루엣:** 흰 경량 갑주, 한쪽 숄더 망토, 활동성 팬츠. 사복은 짧은 스포츠 재킷과 반바지 또는 편한 팬츠. 갑주가 얼굴과 손 동작을 가리지 않게 한다.

**포즈·키아트:** 방패를 고정하고 동료에게 괜찮다는 신호. 충격을 버티는 발 위치와 방패 전개로 무게를 보인다.

**성격의 반전:** 순찰 보고는 짧지만 동료의 간식 취향은 정확히 기억한다.

**로비 움직임:** 장갑 정리 → 주머니의 작은 인형 노출 → 급히 넣고 헛기침.

**새 대사 초안:** “순찰 끝. …돌아오는 길에 네 것도 샀다.” / “그 인형은 경비용이다. 웃지 마.”

#### 리엔 — 무대에서는 대담하지만 첫 관객의 반응은 신경 쓰는 연주자.

**매력의 순서:** 생동감과 솔직한 감정. 활발한 공연 동작을 일률적으로 중립 포즈로 바꾸지 않는다.

**의상·실루엣:** 짧은 공연 재킷, 티셔츠, 플리츠 스커트 또는 리듬감 있는 반바지. 레깅스는 선택 사항이다. 헤드폰·끈·활에 분홍과 노랑 포인트를 반복한다.

**포즈·키아트:** 눈높이 전신에서 활을 휘두르며 한 발 내딛는 피날레. 얼굴·바이올린·리본이 동작의 중심이다.

**성격의 반전:** 공연에는 자신 있지만 새 곡 제목을 정할 때는 동료 의견을 기다린다.

**로비 움직임:** 박자 세기 → 짧은 연주 → 관객에게 손 흔들기.

**새 대사 초안:** “맨 앞자리 비워 놨어요. 박수 안 치면 삐질 거예요!” / “한 번만 더 들어줄래요? 이번엔 마지막 마디까지 왔어요.”

#### 에일라 — 다정함을 말투뿐 아니라 스스로 내리는 결정으로 보여주는 기록관.

**매력의 순서:** 편안함과 단호함. 모두의 보호자 역할에 고정하지 않는다.

**의상·실루엣:** 라벤더·백색의 열린 등 로브 또는 가벼운 기록관 원피스. 종 장식과 땋은 머리를 유지한다. 카페 사복은 짧은 가디건과 다른 헤어 어레인지로 대비한다.

**포즈·키아트:** 책장을 닫고 상대를 보는 미소. 정화 기술은 반원형 빛과 명확한 손동작으로 표현한다.

**성격의 반전:** 평소 조용하지만 동료를 해치는 기록에는 가장 먼저 반대한다.

**로비 움직임:** 작은 종 흔들기 → 옆자리로 찻잔 옮기기 → 짧은 눈맞춤.

**새 대사 초안:** “오늘 기록은 내일 해도 돼요. 지금은 같이 차를 마셔요.” / “이건 지워도 되는 기억이 아니에요. 제가 지킬게요.”

#### 시온 — 기억을 지우는 일을 하지만 사소한 칭찬은 오래 기억하는 사서.

**매력의 순서:** 집중력과 독특한 생활 습관. 낮고 느린 목소리와 긴 코트만으로 개성을 설명하지 않는다.

**의상·실루엣:** 비대칭 셔츠, 허리선이 드러나는 짧은 재킷과 긴 스커트 또는 슬림 팬츠. 책갈피·잉크·종이의 질감을 얼굴 근처 소품으로 연결한다.

**포즈·키아트:** 책갈피를 손끝에서 돌리다 상대를 알아보고 책을 덮는 순간. 소멸 효과는 글자가 흩어지는 명확한 방향성을 갖는다.

**성격의 반전:** 중요 기록에는 엄격하지만 개인 메모는 책 사이에 끼워 두고 잊는다.

**로비 움직임:** 책 읽기 → 쏟아지는 메모 정리 → 태연한 표정으로 책 닫기.

**새 대사 초안:** “지울 기록은 골랐어요. 오늘 대화는 남겨 둘게요.” / “그 칭찬은… 다시 말하지 않아도 기억해요.”

**스킨 방향:** 「접어 둔 책갈피」. 기본복과 다른 실루엣·생활 맥락을 먼저 검증한다. 변경 범위는 구매 전 로비·전투·대표 카드·궁극기·음성 항목별로 표시한다.

#### 카야 — 작은 단서에 강한 자신감을 보이지만 결정적인 순간에는 동료의 말을 듣는 탐정.

**매력의 순서:** 당찬 추리와 장난스러운 경쟁심. 보호받는 막내 대신 조사와 판단의 주체로 둔다.

**의상·실루엣:** 깃털 탐정 모자, 짧은 망토, 반팔 셔츠·베스트, 반바지, 활동성 부츠. 돋보기와 단서 태그를 반복 모티프로 사용한다.

**포즈·키아트:** 단서판 앞에서 새로운 연결을 가리키며 웃는 동적인 전신. 석궁과 시선의 방향이 조사 목표로 이어진다.

**성격의 반전:** 큰 사건은 잘 기억하면서도 자신이 숨긴 간식의 위치는 자주 잊는다.

**로비 움직임:** 돋보기 확인 → 손가락으로 결론 표시 → 잘못 붙인 단서표를 슬쩍 수정.

**새 대사 초안:** “이번 단서는 내가 먼저 찾았어요. 다음 건 같이 찾아요!” / “범인은 아직 몰라도, 공방장이 웃는 이유는 알겠는데요?”

**스킨 방향:** 「축제의 작은 명탐정」. 기본복과 다른 실루엣·생활 맥락을 먼저 검증한다. 변경 범위는 구매 전 로비·전투·대표 카드·궁극기·음성 항목별로 표시한다.

**제작 확인:** 얼굴에서 개성이 읽히는가, 행동이 직업·전투 방식과 연결되는가, 사복과 기본복이 구별되는가, 동료와의 관계가 한 장면에서 드러나는가. 이 브리프는 최종 일러스트나 음성의 완성이 아니다.


#### 루미 — 누구보다 빨리 달리지만 함께 돌아가는 길에서는 속도를 맞추는 배달원.

**매력의 순서:** 스포티함과 솔직한 자신감. 활발한 젊은 성인이라는 인상을 우선한다.

**의상·실루엣:** 회로 무늬의 짧은 재킷, 크롭 스포츠 톱, 바이크 쇼츠, 빛 궤적 운동화. 성인 스포츠 캐주얼과 축제 사복을 대비한다.

**포즈·키아트:** 전격 단검을 들고 전방으로 달리되 얼굴과 경로가 읽히는 구도. 로비는 헬멧을 벗고 배달 완료를 알리는 순간.

**성격의 반전:** 빠른 배달 기록에는 집착하지만 친구에게 주는 물건은 모서리까지 정성껏 포장한다.

**로비 움직임:** 헬멧 벗기 → 작은 포장 꺼내기 → 웃으며 건네기.

**새 대사 초안:** “오늘은 급행 말고 같이 걸어요. 도착 시간은 내가 정할게!” / “이건 배송 목록에 없어요. 공방장한테 주는 거니까.”

**스킨 방향:** 「급행 없는 하루」. 기본복과 다른 실루엣·생활 맥락을 먼저 검증한다. 변경 범위는 구매 전 로비·전투·대표 카드·궁극기·음성 항목별로 표시한다.
