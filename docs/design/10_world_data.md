# 10. 무기·적·구역 데이터

## 10.1 무기 체계

- 캐릭터마다 무기 종류(원거리·근접·장치·의식)가 정해져 있고 **같은 종류만 장착**한다. 한 무기는 한 캐릭터만 장착한다(서버 고유 제약).
- 장착 무기는 ① 전투력(§11.1 W) ② 패시브(정련 R1~R5) ③ **무기 카드 1장**(장착자 속성, 장착자의 카드로 취급: 게이지·잔향)을 준다.
- 등급: 전용 SSR 6(한정 2 + 상시 4, 해당 캐릭터에게 맞춘 패시브), 범용 SSR 4, SR 8, 기본 R 4(종류마다 1개, 제작·기본 지급, 패시브 대신 정련 시 피해·방어 +0~12%).
- 정련: SSR·SR은 같은 무기 중복 획득으로 R1→R5(5개째 이후 초과분은 기억 결정체). 기본 R 무기는 **제련핵**(보스 토큰 교환, §12.5)으로 정련한다.
- 무기 레벨·승급은 §11.

## 10.4 구역 3~5 명세 (P2 콘텐츠 작업)

새 적 행동은 엔진에 다음 의미로 추가한다(이름·정의 고정, `enemyMove`·의도 텍스트·C# 이식·시험 포함).

| 새 행동 `t` | 정의 | 의도 표시 |
|---|---|---|
| `apDrain` | 파티의 다음 턴 행동력 −n(최소 0, 부채와 별개) | "시간 착취 n" |
| `sealSlot` | 파티의 다음 턴 예약 칸 1개 봉인(담보와 같은 규칙, 이미 봉인 중이면 방어 +10으로 대체) | "칸 봉인" |
| `delayRes` | 가장 늦게 건 예약 1개의 만기를 +1턴(칸이 없으면 대신 그 예약 카드를 버린 더미로) | "시간 지연" |
| `silence` | 다음 플레이어 턴 동안 예약 비용 +1 | "침묵" |
| `eatName` | 버린 더미의 무작위 카드 1장을 이번 전투에서 소멸(토큰 우선) | "이름 먹기" |
| `phase` | 체력 0이 되면 쓰러지는 대신 2페이즈로(체력·균열 최대, 패턴 교체). 보스 전용 | "2페이즈" |
