## 19.2 엔진 단위 시험이 보장하는 것

RNG 결정론·경계, 교차 벡터 일치, 메아리·복제 토큰 비용 0 유지, 레벨 대응 배율(방어·회복 = 체력, 반격 = 전투력, 반사 = 스테이지 %), 상점 유물 2개·사건 희귀도(RNG·모집·스탯), 데이터 인덱스, 전투 시작 상태, 기준 전투 피해, 예약 칸(2/1, SLOT_FULL, 다음 턴 해결), 실패 명령의 원자성·사전 검사의 순수성, 멱등·충돌·오래된 버전, 균열(게이지·행동 취소·+25%·행동력 +1), 손패 상한·카드 보존, 계약(선불·부채 상한), 성장 스탯·스테이지 배율·경험치 합 360,000, 장신구 가산, 지도 보장(300시드), 기억 저장(용량·패배 1개·재구성), 용량 성장, 모집(하드 80·픽뚫 확정, SR 10회, 무기 70·75%, 평균 = 정확값 ±3% 몬테카를로, 초심자 50회, 횟수 1/10, 선택권 300, 공명·정련 상한).
