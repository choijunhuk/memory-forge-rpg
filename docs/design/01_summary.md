# 1. 3분 요약

## 1.1 한 문장

**기억을 잃은 공방장이 되어, 소녀·여성 동료 10명의 "기억 카드"로 덱을 짜고, 카드를 지금 쓰거나 다음 턴·다다음 턴에 터지도록 예약해 적의 균열을 깨는 서브컬처 로그라이트 덱빌딩 RPG.** 탐사에서 바뀐 덱은 캐릭터마다 "기억"으로 저장되어 다음 탐사와 고난도 콘텐츠의 시작 덱이 된다(카제나식 세이브).

## 1.2 무엇이 우리 게임인가

| 층 | 내용 | 출처 |
|---|---|---|
| 서브컬처 공통 | 캐릭터 모집(반천장 50:50, 풀천장), 중복 = 성능(공명 1~6), 전용 무기 모집(75:25), 인연(호감도)·로비·스킨, 42일 시즌·패스·월정액, 주간 보스, 2주 순환 고난도(기록 균열), 성장 던전·소탕 | 장르 관례 |
| 카제나 방식 | 탐사(런) → 바뀐 덱을 캐릭터별 기억으로 저장(용량 제한, 패배 시 1개), 탐사 중 카드 변주(부품 3택 1), 저장된 덱으로 고난도 진행 | 카오스 제로 나이트메어 계열 |
| 우리만의 것 | ① **시간 예약**: 비용은 지금, 효과는 다음 턴/다다음 턴(절대 턴·칸 제한·봉인·앞당김) ② **균열**: 약점 속성으로 게이지를 깨면 다음 행동 취소 + 받는 피해 +25% + 행동력 +1 → 예약을 균열 타이밍에 맞추는 퍼즐 ③ **캐릭터마다 다른 규칙**(잔향·과부하·성장/진화·계약·반격·표식·소멸) ④ 얼굴 없는 비전투 주인공의 **기억 찾기** 이야기 | 이 문서 |

## 1.3 핵심 수치

| 항목 | 값 |
|---|---|
| 전투 | 행동력 4/턴(최대 9), 손패 5(최대 10), 예약 칸 다음 턴 2(최대 3)·다다음 턴 1(최대 2), 파티 3명 공유 체력 |
| 균열 | 게이지 0 → 다음 행동 1회 취소, 다음 플레이어 턴 끝까지 받는 피해 +25%, 다음 턴 행동력 +1(턴당 최대 +2) |
| 탐사 | 7층 + 보스(짧게, 약 15분) / 2구역(정규, 약 30분). 모든 경로에 보스 전 전투 3회 이상 |
| 기억 저장 | 캐릭터당 용량 6(승급 2·4단계와 공명 4에서 +1, 최대 9). 패배 시 변경 1개만 |
| 모집 | 한정 캐릭터: SSR 0.8%, 66회부터 확률 상승, 80회 확정, 픽업 50% → 최대 160회. 무기: 0.9%, 60회부터, 70회 확정, 픽업 75% → 최대 140회. SR 이상 10회 보장 |
| 정확 기대값 | 캐릭터 SSR 평균 53.41회(종합 1.872%), 픽업 평균 80.12회. 무기 SSR 48.30회, 픽업 60.37회 |
| 무과금 42일 | 결정 13,920 + 한정권 9 = 한정 96회(기록 균열 제외 81회). 천장 0에서 시즌 안에 픽업 확보 68.9% |
| 성장 | Lv.60(승급 4단계), 무기 Lv.60, 스킬 2계열 Lv.10, 장비 2칸 +15. 1명 완성 = 성장 던전 131회(집중 2,620), 승급 핵 14개(주간 보스 2.33주) |
| 등급 목표 | 15세 이용가. 성인 6명은 팬서비스 적극 활용, 10대 4명은 성적 대상화 금지(§9.1) |

## 1.5 지금 바로 해 볼 수 있는 것

`prototype/index.html`을 브라우저로 연다(인터넷이 없으면 시스템 글꼴로 표시). 탐사 3명 편성 → 지도 → 전투(지금/예약/다다음, 균열, 필살기) → 보상·휴식·공방·상점·사건 → 기억 저장 → 다음 탐사에서 저장 덱으로 시작. 모집 시뮬레이터에서 반천장·무기 배너·공명이 탐사에 바로 반영된다. 아트·연출은 들어 있지 않은 **규칙 검증용 시제품**이다.
