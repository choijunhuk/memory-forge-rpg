| ID | 이름 | 대상 | 규칙 |
|---|---|---|---|
| `vul` | 취약 | 적 | 받는 피해 +25%. 라운드 종료 시 1 감소. |
| `weak` | 약화 | 양쪽 | 주는 피해 -25%. 적은 라운드 종료, 파티는 플레이어 턴 종료 시 1 감소. |
| `mark` | 표식 | 적 | 고정 대상 카드의 조건. 라운드 종료 시 1 감소. |
| `burn` | 화상 | 적 | 라운드 종료 시 화상 수치만큼 피해(방어 무시) 후 1 감소. |
| `str` | 힘 | 적 | 공격 1회마다 피해 +수치. 지속. |
| `broken` | 균열 | 적 | 균열 게이지 0: 다음 행동 1회 취소, 다음 플레이어 턴 종료까지 받는 피해 +25%. 파티 다음 턴 행동력 +1(턴당 최대 +2). |
| `counter` | 반격 | 파티 | 적의 공격 1회마다 공격한 적에게 반격 수치만큼 피해. 플레이어 턴 시작 시 0. |
| `charge` | 충전 | 파티 | 다음 피해 카드 1장의 피해 +n%. 사용하거나 기간이 끝나면 사라짐. |
| `reflect` | 반사 | 적 | 카드 피해를 받을 때마다 파티가 반사 수치만큼 피해. 적 행동 시작 시 사라짐. |

| 키워드 | 규칙 |
|---|---|
| 소멸 | 사용 후 이번 전투에서 제외(소멸 더미). |
| 계약 | 즉시 사용 전용. 부채·봉인 등 미래 비용이 있다. |
| 전투당 n회 | n회 사용하면 소멸. |
| 예약 | 비용을 지금 내고 다음 턴(또는 다다음 턴) 시작에 해결. 예약 수치가 따로 적힌 카드는 그 수치를 쓴다. |
| 예약 전용 | 즉시 사용할 수 없다. |
| 다다음 턴 전용 | 다다음 턴 예약만 가능. |
| 고정 대상 | 표식이 있는 적만 지정 가능. 해결 시 대상이 죽었거나 표식이 없으면 불발(비용 환급 없음). |
| 성장 | 예약으로 해결될 때 성장 +1(카드당 전투 1회, 파티 전투당 3회). 성장 3이면 전투 보상 화면에서 진화 분기 선택. |
| 과부하 n | 사용 시 파티 체력 n을 잃는다(방어 무시). |
| 충격 n | 속성과 관계없이 적의 균열 게이지를 n 깎는다. |
