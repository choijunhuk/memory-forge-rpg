# 8. 기억 저장 (카제나식 세이브)

## 8.1 개념

- 캐릭터마다 **기억 덱**이 1개 있다. 처음에는 기본 덱(그 캐릭터의 시작 카드 4장 + 지정 공용 카드 1장).
- 탐사가 끝나면 이번 탐사 덱이 기본 덱과 **어떻게 달라졌는지**를 변경 목록으로 보여 주고, 캐릭터별 **기억 용량** 안에서 남길 변경을 고른다. 고른 변경만 반영한 덱이 새 기억 덱이 된다(이전 기억 덱은 이력으로 보관).
- 기억 덱은 다음 탐사의 시작 덱이며, 주간 보스·기록 균열·성장 던전의 전투 덱이다(무기 카드는 장착 무기에서 매번 추가).

## 8.2 용량

`용량 = 6 + (승급 2단계 이상 +1) + (승급 4단계 +1) + (공명 4 +1)` → 최대 9.

## 8.3 변경과 비용 (`data.rules.memoryCost`)

| 변경 | 비용 | 판정 |
|---|---|---|
| 기본(B) 카드 추가 | 1 | 기본 덱에 없는 그 캐릭터 카드 |
| 고급(A) 카드 추가 | 2 | |
| 희귀(S) 카드 추가 | 3 | 진화 카드는 원본 카드의 희귀도로 계산 |
| 공용 카드 추가 | 1 | 그 캐릭터에게 배정된 공용 카드 |
| 강화(+) | 1 | 기본 덱 카드의 강화, 또는 추가 카드에 포함 |
| 부품(일반 / 희귀) | 1 / 2 | 칸마다(회로·각인) |
| 진화 | 2 | 기본 덱 카드가 진화했거나, 추가 카드에 포함 |
| 카드 제거 | 1 | 기본 덱 카드가 덱에 없음 |

추가 카드의 비용 = 카드 비용 + (강화 1) + (진화 2) + 부품 비용 합. 예: 희귀 카드에 희귀 부품을 붙이고 강화했다면 3 + 2 + 1 = 6.

## 8.4 변경 목록 계산 (`Run.memoryChanges`)

1. 캐릭터의 기본 덱을 만든다.
2. 이번 탐사 덱에서 그 캐릭터의 카드(고유 카드, 그 캐릭터에게 배정된 공용 카드)를 모은다. 무기 카드·토큰·저주는 제외.
3. 기본 덱 카드마다 같은 ID(또는 그 카드에서 진화한 카드)를 하나씩 짝짓는다. 짝이 없으면 "제거", 짝이 진화했으면 "진화", 강화했으면 "강화", 부품마다 "부품" 변경을 만든다.
4. 짝이 지어지지 않은 나머지 카드는 각각 "추가" 변경이다.
5. 변경 목록은 결정적 순서(기본 덱 순서 → 추가 순서)를 가진다. 선택은 이 목록의 **인덱스**로 보낸다.

## 8.5 저장 규칙 (`Run.commitMemory`)

- 정상 종료(완주·귀환): 캐릭터마다 고른 변경 비용 합 ≤ 용량(`OVER_CAPACITY`).
- **패배: 파티 전체에서 변경 1개만**(`DEFEAT_KEEP_ONE`). 용량 검사도 함께 한다.
- 고르지 않은 변경은 버려지고, 덱은 기본 덱에서 고른 변경만 반영해 다시 만든다(이전 기억 덱 기준이 아니라 **기본 덱 기준**으로 차이를 계산하므로, 이전 저장 내용을 유지하려면 그 변경도 다시 선택돼 있어야 한다).
- 공용 카드 배정: 새로 얻은 공용 카드는 기본으로 편성 1번 캐릭터에게 배정되며, 저장 화면에서 바꿀 수 있다(`Run.assign`).
- 저장은 서버 트랜잭션 1회로 처리하고(§17.2) 캐릭터별 이전 덱을 `memory_deck_history`에 남긴다.

## 8.6 저장 화면 UX

- 캐릭터별 카드 영역: 용량 막대(사용/최대), 변경 목록(체크박스, 비용, 카드 미리보기), 결과 덱 미리보기.
- 기본 선택: 정상 종료면 **이전 기억 덱에 있던 변경을 먼저**, 남은 용량으로 새 변경을 목록 순서대로 체크한다(프로토타입은 목록 순서대로만 체크). 패배면 아무것도 체크하지 않는다.
- 용량 초과·패배 2개 이상이면 저장 버튼을 비활성화하고 이유를 표시한다.
- "저장하지 않기"는 확인 대화를 거친다(기억 덱은 바뀌지 않음).

## 8.7 설계 의도와 경계

- 저장은 **덱의 모양**만 남긴다. 유물·동전·체력·지도 진행은 남지 않는다.
- 용량은 레벨이 아니라 승급·공명으로만 늘어난다: 장기 목표가 되되, 무과금도 승급 4단계로 8까지 도달한다.
- 강한 카드를 무한히 쌓지 않도록 추가 비용이 희귀도에 비례한다. 카드 제거(덱 압축)에도 비용 1을 받는다.
- 패배 1개 규칙은 "도전의 대가"이며, 고난도 탐사에서도 최소한의 진전이 남게 한다.
