## 전체 게임에서 남은 것

다음은 이번 UI 완료로 해결됐다고 볼 수 없는 범위다. 상세 장별 상태는 [IMPLEMENTATION_STATUS](IMPLEMENTATION_STATUS.md), 승인 경계는 [결정 장부](decisions_v0.8.1.md)를 따른다. 과거 미완료 문구가 후속 수용으로 해결됐는지 최신 보고서를 먼저 확인한다.

1. **실계정·운영 서버 연결**: 현재 UI는 별도 Development 선택형 연습 서버/신뢰된 fixture다. 실제 인증·보유권·안전한 시작 구성·다기기/전체 앱 재시작·운영 이관/보안/부하 수용이 남았다. 파일/PG 백엔드의 기존 구현·시험과 이번 실제 UI 수용을 구분한다. 결제·가챠/재화 원장·영구 자산 의미/운영 배포는 승인 경계를 유지한다.
2. **전투/저장 실제 조합 수용**: 실제 모든10명/공명·Sera 다중 대상 필살기, 미확정 필살기 복구, 긴 설명/최악 밀도/130% 글자·공용 카드 실제 배정 양성·동일 부품2개/기존 칸 교체·temp 슬롯 표시·모든 실제 서비스/사건/보상 경로. 일부는 자동 fixture로 검증됐으므로 구현을 중복하지 말고 실제 수용의 빈칸부터 채운다.
3. **후반 난도와 본편 활성화**: 최초1320회에서 목표 미달32개, 후속5280회 확대 검사에서 장부 기준21개가 남았다. 기존 수치/원문을 임의로 조정하거나 후보를 본편 활성화하지 않는다. 최신 검사/원인 분석/승인 경계를 대조한다. 이번 표시 UI는 밸런스 개선 증거가 아니다.
4. **제품 전체 UI/콘텐츠/아트**: 로비/편성·온보딩·성장/수집의 운영 루프·전체 서사/장면·완성 아트/애니메이션/음향·현지화와 게임 전체 일관성 수용. 스타터 자산9개는 시작용이며 전체10명/카드/적/배경/스킨 세트 완료가 아니다. 이미지 생성·내용 수정·캐릭터 외형 최종 디자인은 Codex 전담이다.
