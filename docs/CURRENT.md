## 개발 진행 — 2026-10-15 / P1-LATE-ACTIONS-BALANCE

이 절이 위 개발 기록의 후반 적 행동·동일 조건 검사 상태를 갱신한다. JS Battle에 `apDrain`, `sealSlot`, `delayRes`, `silence`, `eatName`, `phase`를 구현했고 HTML 의도·사전 안내·로그·페이즈 상세를 연결했다. 착취는 부채와 별도로 합산하고, 봉인과 지연은 다음 플레이어 턴의 기본 칸을 기준으로 처리한다. 지연은 원래 예약 위력을 유지하며 초과 시 버리고 이미 낸 행동력을 환급하지 않는다. 침묵은 +1 비중첩·무료 우선이며, 이름 먹기는 토큰 우선 소멸과 기존 훅·RNG를 따른다. 무명은 첫 HP 0에서 새 몸으로 전환하고 처치 훅은 최종 사망 때만 실행한다.
