## 2026-10-15 추가 사용자 지시 — 현재 실행 우선

충돌 시 이 절과 `docs/AI_WORKFLOW.md` §10이 기존 모델 역할표·배포판 시작 순서에 우선한다. **Codex는 `gpt-6.1-sol`만, Claude는 Opus(`claude-opus-5-5`)만** 사용한다. Astra·Fable·Luna·다른 모델·자동 fallback은 금지한다. 두 계정의 기존 5배 구독 포함 사용량만 쓰며 API/Console/구매 크레딧·추가 사용·자동 충전은 금지한다. 사용량 절약보다 품질을 우선한다.

기본 **High**, Codex의 핵심 전투·예약·카드/부품·기억·경제·인증·서버·이관·아키텍처·복잡한 버그·중요 계획·최종 검증과 Claude의 종합 계획·서사·캐릭터·최종 검토에는 **Max를 적극 사용**한다. Medium 이하를 관성적으로 선택하지 않고 담당 AI가 자율 결정한다. 실제 CLI·설정에서 지원·적용 여부를 확인하며 프롬프트 선언을 실행 증거로 세지 않는다. Claude Max는 지원되는 세션 CLI/환경 경로로 적용하고 미지원 영구 `modelSettings` 값으로 저장하지 않는다.

주요 작업 전에 요구사항 절·게임 내 역할·완료 조건·담당 파일을 기록하고 **개발 → 시험 → 반대편 AI 독립 검토 → 수정 → 재검증 → 통합 → 다음 작업**을 반복한다. 핵심 결함·명세 위반은 해결·재검토 전 통합하지 않는다. 두 차례 미해결이면 대안·근거·위험을 남기고 해당 항목만 보류한다. P1/P2 완료를 세션 종료 조건으로 삼지 않고 다음 로드맵 작업을 계속한다. 정책·권한·환경·한도 차단도 해당 작업만 보류하며 세션 밖 지속 작업을 약속하지 않는다.

Codex가 공식 Claude CLI를 별도 worktree에서 직접 호출·회수하며 실제 세션·모델·노력·종료·검증 증거를 남긴다. 재귀 호출은 금지한다. Unity MCP를 실제 Editor의 Scene·Prefab·UI·Animation·Console·Play 시험·임포트·빌드에 적극 사용하되 한 씬·프리팹 쓰기 담당을 지킨다. 설치만으로 연결을 주장하지 않고 유료 `asset_gen` 공급자는 사용하지 않는다. 이미지 생성·내용 수정은 Codex, Claude는 브리프·검수·비생성형 적용 담당을 유지한다.

설정과 실제 실행 증거는 `docs/AI_ENVIRONMENT.md`, 현재 개발 상태는 `docs/CURRENT.md`를 따른다. 기존 설계 v0.8.1·수치·승인 경계·비공개 원격·변경 이력은 보존하고 기능/시험 축소로 통과시키지 않는다. 자동 시험은 Unity Play·실기기 수용 증거와 구분한다.

## 2026-10-15 추가 지시 — 추론 수준 자율 선택

High·Extra High(`xhigh`)·Max를 실제 지원 범위에서 작업 난이도·위험·검증 결과에 맞춰 자율 선택한다.
