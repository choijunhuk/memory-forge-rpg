# 성장·장비·카드 변주·파트너 확장 검토

상태: **검토 제안**. 2026-10-21 사용자 요청에 따른 현황 대조와 우선순위이며, 새 기능 구현 완료나 경제/영구 자산 규칙 변경 승인이 아니다. 현재 진행 중인 포기·공방 복귀와 UI 수정은 별도로 검증한다.

## 현재 플레이와 끊어진 곳

모집은 실제 Development 계정에 저장된다. 다만 일반 로비의 탐사는 고정 연습 편성이며, 모집한 동료·공명·무기가 실제 편성/성장/출격에 반영되는 제품 흐름은 아직 없다. “계산 코드가 있다”와 “플레이어가 계정에서 성장시킬 수 있다”를 구분해야 한다.

| 요소 | 이미 있는 것 | 플레이어에게 빠진 연결 |
|---|---|---|
| 동료 성장 | 레벨·승급·스킬 비용/재료 데이터와 전투 스탯 계산 | 계정 재료 소비·육성 거래·성장 화면 |
| 공명 | 실제 중복 모집·보유 수·공명 결과 저장, Core 공명 효과 | 보유 공명을 실제 출격 입력에 반영 |
| 무기 | 실제 무기 모집/중복 저장, 레벨·승급·정련 규칙/계산·고유 카드 | 보유 장착·교체·육성 거래와 화면 |
| 갑주·장신구 | 제작·강화 비용과 전투 계산 | 실제 제작·장착·강화와 계정 보존 |
| 카드 강화/회로/각인 | 탐사 강화·부품 선택·교체·기억 저장 | 변화 전후와 다음 출격 효과를 홈에서 쉽게 확인 |
| 성장·분기 진화 | 유리의 성장 카드5종에 각2분기, 실제 진화 명령/UI | 전원 공통 번뜩임은 아님. 고정 연습 편성에서는 유리 사용도 연결되지 않음 |
| 기억 덱 | Core v2와 개발 서버 파일/PG 이력·영수증 저장 | 일반 로비와 실제 계정 탐사/기억 관리의 통합. 로컬 연습은 앱 세션 범위 |
| 인연 | 인연 규칙/보상 데이터와 로비 대본 미리보기 | 실제 인연 XP·선물·해금·보상 원장. 현재 미리보기는 조건을 적용한 해금이 아님 |
| 도전/임무 | 콘텐츠 모드 Core와 일부 진행 데이터/함수 | 계정 진행·도전·보상 지급 UI/API. 일부 적 구성·회전 조건은 결정 대기 |
| 파트너 | 기존 기획이 이 역할을 전용 무기 모집으로 대체 | 별도 파트너 수집/편성/스킬/성장 시스템 없음 |

## 카제나에서 구분할 축

번뜩임은 카드의 효과·비용 등을 바꾸는 빌드 선택이며 장비 강화와 같은 시스템이 아니다. 공식 설명에는 번뜩인 카드를 다시 선택하는 명상도 등장한다. 장비는 별도의 효과/발동 조건과 재련 같은 선택을 가진다. “장비 번뜩임”을 합쳐 부르는 공식 시스템명은 확인하지 못했다. [시즌2 공식 설명](https://page.onstove.com/chaoszeronightmare/kr/view/11847469), [출격의 장비 설계](https://page.onstove.com/chaoszeronightmare/kr/view/12541608).

신 번뜩임은 ‘새 번뜩임’이 아니라 신별 카드 강화다. 10/21 공식 공지는 신별 전용 재화로 선택 부여하는 편집과 파트너의 탐사 패시브 추가를 설명한다. 이 게임의 특정 획득 비용·확률·진행 규칙을 Memory Forge에 그대로 확정하지 않는다. [2026-10-21 공식 업데이트](https://page.onstove.com/chaoszeronightmare/kr/view/14593113).

장기 육성과 파트너 매칭도 회차 안의 카드/장비 선택과 구분된다. 기억의 조각은 부위·옵션·세트를 가진 별도 성장 장착축이다. [공식 기억의 조각 안내](https://page.onstove.com/chaoszeronightmare/kr/view/11022847), [육성·파트너 UI 공지](https://page.onstove.com/chaoszeronightmare/kr/view/14554833).

## 권장 순서

1. **수집 → 편성 → 실제 출격.** 서버가 모집 원장의 보유·공명·무기를 검증하는 편성/출발을 먼저 연결한다. 고정 연습판과 실제 계정 탐사를 명확히 나눈다. 성공 기준은 새로 얻은 동료를 선택하고, 그 보유 공명·장비가 실제 전투 입력에 반영되고, 재접속 후에도 같은 편성이 남는 것이다.
2. **동료 육성 + 장비 관리.** 승인된 레벨/승급/스킬/제작 비용을 재사용한다. 재료 획득 경로가 없는 상태에서 버튼만 만들거나 무료 재료를 임의 지급하지 않는다. 계정 성장·소비·상한·멱등 영수증을 함께 구현해야 실제 성장이다. 무기 장착·교체·강화·정련은 같은 거래 경계에서 검증한다.
3. **카드 빌드 성과를 눈에 보이게.** 기존 강화/회로/각인/유리 진화의 전후 비교, 저장한 기억의 변화, 다음 출격 덱을 연결한다. 새로운 전원 공통 분기를 만든다면 즉발/예약/기억 연동처럼 이 게임의 전투 역할을 바꾸는 방향으로 검토한다. 숫자만 커지는 또 하나의 강화축은 피한다.
4. **성장한 덱으로 도전할 곳.** 이미 규칙/Core가 있는 주간 보스를 우선 검토하고, 실제 적 구성·해금·보상 지급·재도전 상태까지 한 단위로 연결한다. 미작성 회전/별 조건이 있는 콘텐츠는 완료로 보이지 않게 한다.
5. **인연의 실제 진행.** 플레이/선물로 진척되고, 로비 반응과 에피소드가 해금되는 흐름을 완성한다. 기존 동료에게 애착을 갖는 기능을 새 수집 상품보다 먼저 만든다.

## 파트너와 희귀 카드 강화의 구체적 검토안

| 제안 | 역할 | 기존 요소와의 경계 | 새로 결정할 것 |
|---|---|---|---|
| 보유 동료의 지원 편성 | 출격하지 않은 동료가 보호·구조·정보 같은 지원을 담당 | 전용 무기는 카드/장비 조건을, 지원 동료는 행동 지원을 담당 | 슬롯·조건·사용 제한·효과·성장/공명 적용·기억 저장 영향 |
| 별도 수집형 파트너 | 독립된 지원 캐릭터와 인연·성장 | 기존 “파트너 대신 전용 무기” 설계를 확장하므로 중복 성장축 위험이 큼 | 획득처·보유/중복/영구성·편성·새 모집 여부·경제 전체 |
| 회차 카드 분기 | 같은 카드를 다른 타이밍/역할로 쓰는 선택 | 기존 유리 진화와 공방 부품을 대체할지 보완할지 먼저 결정 | 대상·발생 조건·선택/무작위·상한·취소/재선택·보존 규칙 |
| 희귀한 심층 변주 | 중요한 발견/도전으로 카드 운용을 크게 바꿈 | 일반 강화/각인과 효과 중복을 피하고 기억 용량과 함께 설계 | 획득 경로·상한·실패 회수·저장 비용·영구성. 확률/가격은 미정 |

우선 추천은 **별도 새 뽑기 파트너보다 기존 보유 동료를 쓰는 지원 편성**이다. 이는 새 규칙 제안이며 현재 구현에 조용히 넣지 않는다. 기존 설계의 전용 무기 수집과 중복되는 보너스/필수 육성 숙제를 늘리지 않는 것이 목적이다.

원하는 랜덤 강화가 나오지 않으면 즉시 포기·재시작하는 구조도 경계한다. 카제나 개발진 역시 이 반복과 최적 세이브 압박이 다양성을 해친다고 진단했다. Memory Forge에서는 발견 기록·선택지 해금·재선택·실패 성과 회수 같은 장치를 먼저 검토할 만하다. 실제 획득량·보존 의미는 기존 기억 규칙과 함께 결정한다. [공식 시즌2 문제 진단](https://page.onstove.com/chaoszeronightmare/kr/view/11847469), [출격 도입 이유](https://page.onstove.com/chaoszeronightmare/kr/view/12541608).

이 문서는 제안이다. 새 파트너·재화·확률·가격·영구 보존 규칙이나 운영 배포를 확정/적용하지 않았다. 코드/UI 구현, Core 계산, 실제 계정 거래, PC/실기기 수용은 앞으로도 따로 증명한다.
