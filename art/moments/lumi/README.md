`motions.stage_settle`: 0.75초 동안 figure 슬롯을 y=0→−3→0으로 옮기는 3키 정착 움직임. 1920×1080 기준 px, 회전 0·크기 1·불투명도 1, `inOut`, 비반복이다. **JSON 데이터 작성 READY**이고 손·안경·종·찻잔·헬멧을 실제로 움직이는 클립은 아니다. 로비 A는 실제 PNG를 참조하며, 실제 AnimationClip·리그·Timeline·VFX·프레임·음성 파일은 0개다.

## 입력·반복·음성

A/B/C 모두 `skippable: true`, `advance: tap`, `repeatable: true`. 글자 출력 중 탭은 전체 표시, 출력 후 탭은 다음 박자, 건너뛰기는 장면 종료, 다시 보기는 최초 박자부터가 형식상 의도다. 재시작에서 카메라·figure 정착 상태를 초기화하는 것은 Claude 재생기 검수 항목이다. B/C의 `cooldown_s: 0`은 감상 재생 데이터이며 게임 정책 변경이 아니다. 반복 재생은 기록·기억·인연 보상을 지급하지 않는다.

모든 발화의 톤은 `beats[].line.tone`에 있다. 무성 지문은 음성 녹음 대상으로 세지 않는다. `voice` 파일 경로는 만들지 않았으며 `assets`의 voice는 TODO다. 배경음은 `silence`로 명시했다. 종·종이·발소리는 대본의 연기 단서이며 실제 SFX 재생을 데이터에 추가하지 않았다. 자동 건너뛰기나 누락 대사 축약으로 길이를 맞추지 않는다.
