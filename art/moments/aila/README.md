## B — 기존 인연 「비어 있는 서랍」의 완결 대본

기존 인연 1화 제목 안의 완결 초안. 시작: 에일라가 먼저 의자를 당겨 차에 초대. 핵심: 빈 서랍의 불편함을 말하고 자신이 먼저 초대한 오늘의 문장을 쓴다. 끝: 한 장을 보관한 뒤 옆자리에서 다음 잔을 청한다. 서랍이 빈 과거의 이유·상실의 정답·기억 회복은 새로 확정하지 않는다.

이유: 비어 있는 자기 서랍 앞에서 설명을 강요받지 않고, 자신이 고른 평범한 저녁 한 장을 먼저 남겨 본다. 현재 장면 안에서 원인→머뭇거림→상대의 반응→자기 선택→관계의 작은 변화까지 끝난다. 본편 비밀의 해답이나 새 인물·과거사를 확정하지 않는다. 공방장의 행동과 반응은 지문으로 적고 미지원 플레이어 화자 ID를 만들지 않았다.

- 분량: **2509자**, 22박자. `sum(len(beat.line.text))` Unicode 문자 수이며 제목·화자·연기 지시 제외, 공백·문장부호 포함. 요약이나 시놉시스가 아니라 말과 무대 행동이 연속되는 한 편이다.
- 시작 전신, 서랍/책/헬멧의 행동은 미디엄, 감정이 새는 발화는 바스트. 마지막은 미디엄으로 물러나 상대를 기다릴 공간을 남긴다.
- `gaze`는 연기 지시다. 눈동자 리그·자동 시선 추적 구현이 완료되었다는 뜻이 아니다. 로비 핵심 표정·손동작은 아래 ready 키포즈 전환으로 표현하며, 연속 관절 동작은 별도 제작이 필요하다.
- 기존 인연 해금 상태에서 선택한다. 새 인연 레벨·비용·보상·예약·기억 회복 규칙을 제안하지 않는다.

`motions.stage_settle`: 0.75초 동안 figure 슬롯을 y=0→−3→0으로 옮기는 3키 정착 움직임. 1920×1080 기준 px, 회전 0·크기 1·불투명도 1, `inOut`, 비반복이다. **JSON 데이터 작성 READY**이고 손·안경·종·찻잔·헬멧을 실제로 움직이는 클립은 아니다. 로비 A는 실제 PNG를 참조하며, 실제 AnimationClip·리그·Timeline·VFX·프레임·음성 파일은 0개다.

## 입력·반복·음성

A/B/C 모두 `skippable: true`, `advance: tap`, `repeatable: true`. 글자 출력 중 탭은 전체 표시, 출력 후 탭은 다음 박자, 건너뛰기는 장면 종료, 다시 보기는 최초 박자부터가 형식상 의도다. 재시작에서 카메라·figure 정착 상태를 초기화하는 것은 Claude 재생기 검수 항목이다. B/C의 `cooldown_s: 0`은 감상 재생 데이터이며 게임 정책 변경이 아니다. 반복 재생은 기록·기억·인연 보상을 지급하지 않는다.

모든 발화의 톤은 `beats[].line.tone`에 있다. 무성 지문은 음성 녹음 대상으로 세지 않는다. `voice` 파일 경로는 만들지 않았으며 `assets`의 voice는 TODO다. 배경음은 `silence`로 명시했다. 종·종이·발소리는 대본의 연기 단서이며 실제 SFX 재생을 데이터에 추가하지 않았다. 자동 건너뛰기나 누락 대사 축약으로 길이를 맞추지 않는다.
