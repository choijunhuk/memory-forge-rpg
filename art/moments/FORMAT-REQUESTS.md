# 형식 확장·구현 확인 인계

현재 18장면은 `memory-forge-moments/1`의 필드로 작성했다. **필수 형식 확장은 요청하지 않는다.** 새 필드를 조용히 추가하거나 게임 재생기를 수정하지 않았다.

연결 시 확인할 항목(확인 전 결함으로 단정하지 않음):

1. 세라 `check_time`은 같은 PNG를 다시 참조하는 5프레임·2fps·비반복 시퀀스다. 종료 뒤 다음 beat의 `fig_smile`로 이어져야 한다. 검토용 APNG를 Unity 원본 대신 임포트하지 않는다.
2. 프레임 재생 중 건너뛰기·화면 이탈은 코루틴/카메라/슬롯 상태를 정리해야 한다. 연타로 중복 반응을 겹치지 않는다. 접근성의 모션 줄이기는 최종 포즈와 대사를 보존하는 방식으로 검토한다.
3. `gaze`, `line.tone`은 연기 지시다. 문자열만으로 눈·손·표정을 실제로 움직였다고 표시하지 않는다. 그림 todo인 장면은 의도대로 비워 두고 대사만 재생한다.
4. 슬롯 키프레임은 전신 무대 이동이며, 찻잔 건네기·안경 정리·헬멧 회전 같은 관절 동작을 대신하지 않는다. 그림이 없는 자리에 기존 타 캐릭터나 임시 도형을 넣지 않는다.
5. 자동 진행의 `hold`와 글자 표시·음성 재생이 어떤 순서로 겹치는지 실제 화면에서 확인한다. 너무 짧다면 원문을 줄이지 말고 표시·입력 처리를 수정 요청한다.

이 파일은 쓰기 허용 범위 때문에 `art/requests/` 대신 `art/moments/`에 둔다. 향후 뼈대 리그·립싱크·독립 의상 물리까지 제작하면 그때 실제 필요한 형식만 추가 요청한다.
