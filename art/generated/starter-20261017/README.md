# 기억 공방 초기 3인 아트셋 — 개발 시안

세라(24), 하린(26), 니아(17)의 디자인 시트·카드 컷인·투명 SD 각 1장, 총 9장이다. 원본 v0.8.1 §9·§15와 기존 브리프를 사용했다. 나이·게임 수치·전투 규칙은 바꾸지 않았다.

| 종류 | 수량 | 실제 원본 크기 | 형식 |
|---|---:|---|---|
| 디자인 시트 | 3 | 1774×887 | RGB PNG |
| 카드 컷인 | 3 | 1086×1448 | RGB PNG |
| SD | 3 | 1254×1254 | RGBA PNG, 실제 투명 알파 |

Codex가 생성·수정했다. 첫 로컬 ComfyUI 시안은 세라의 장총·모래시계 약실 누락과 과장된 눈 문양 때문에 채택하지 않았다. 사용자가 승인한 품질 전환 조건에 따라 이후 9장은 Codex 내장 이미지 도구로 제작했다. 내장 도구는 이미지 백엔드 모델명을 반환하지 않아 임의로 이름을 붙이지 않는다.

세라 시트는 v02에서 다리 의상 일관성을, SD 3장은 v02에서 2.5등신에 가까운 지도용 비율을 수정했다. 원본과 미채택 시안은 `art/candidates/20261017/`, 프롬프트·참조 관계·해시는 `manifest.json`, `generation-prompts.json`, `sd-v02-prompts.json`과 `art/provenance.csv`에 보관한다.

Unity 후보 자산은 `Assets/Art/Candidates/Starter20261017/`에 있고, 검수 씬은 `Assets/Scenes/MemoryForgeArtReview.unity`다. 실제 Editor Play Mode에서 9개 텍스처와 투명 SD를 확인했다. 원본 PNG를 바꾸지 않고 검수용 임포트에 mipmap·trilinear 필터를 적용했다.

이 패키지는 내부 선택한 개발 시안이다. 시트의 원본 크기는 최종 설계 규격 2048×1024보다 작다. 나머지 7명, 모집 키아트·표정, 캐릭터별 고유 카드 12장, 레이어 PSD·리그·애니메이션은 완료되지 않았다. 기존 게임 씬의 최종 아트 연결과 Claude의 아트 교차 리뷰도 별도 작업이다.
