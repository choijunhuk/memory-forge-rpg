# 이미지 요청: 탐사 화면 UI 스킨 키트 (2026-10-18)

요청: Claude(UI/UX). 생성·내용 수정: Codex. 이 파일만으로 Codex가 실행됐다고 보지 않는다.

## 왜

사용자 판정: 지금 탐사 화면은 "웹사이트 게임 같다, 모바일 게임이 아니다". 서브컬처 모바일 게임 화면을 직접 보고 정리한 문법은 `reports/expedition_ui_20261018/subculture_ui_reference.md`에 있다. 그 문법대로 화면을 다시 짜려면 **장식 UI 원본**이 필요하다. 코드로 만든 둥근 사각만으로는 카드 틀, 보석, 장식 테두리의 질감이 나오지 않는다.

## 세계관·톤 (기존 Codex 1차안 유지)

`art/candidates/20261018/codex/design-spec.md`의 "자정에 멈춘 시계 도시, 황동에 붙잡힌 기억빛"을 따른다.

- 색: 남색 바탕(#0d1322), 패널 #141c31, 황동 #e2b45f, 기억빛 청록 #62d6c6, 위험 #ff6f6f, 잉크 #e9eef8.
- 문양: 시계 문자판, 톱니, 태엽, 종, 잉크 얼룩, 종이 가장자리.
- 속성 색은 속성 아이콘·카드 테두리 강조에만 쓴다(전격·화염·빙결·공허, 기존 `ico_attribute_*` 톤).
- 사람 얼굴·글자·숫자는 그림에 넣지 않는다. 글자와 숫자는 게임이 그 위에 쓴다.

## 검수 기준 (Claude가 확인)

- 9-slice로 늘렸을 때 모서리 장식이 찌그러지지 않는다.
- 글자·숫자를 얹을 자리가 비어 있고 대비가 충분하다.
- 1600×900 기준 화면에서 카드 184폭, 휴대폰 2340×1080에서 손패가 읽힌다.
- 동작 줄이기 상태에서도 정지 이미지만으로 상태가 구분된다(빛·움직임에 의존하지 않음).
- 기존 1차안의 배경·적 그림과 톤이 맞는다.
