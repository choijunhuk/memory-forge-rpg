## 요청

0. **조사 먼저 (사용자 지시: "서브컬처 캐릭터들의 그 특징에 대해서 조사하게 시켜줘").** 한국·일본·중국 서브컬처 수집형 게임 캐릭터 일러스트의 특징을 공식 자료(공식 일러스트, 캐릭터 소개, 스킨 소개, 개발자 노트 등)로 조사한다. 얼굴 비례와 눈·코·입 표현, 선화와 채색(셀/반셀/페인터리), 머리카락·피부·의상 질감, 실루엣과 의상 디자인 언어, 색 구성, 표정과 포즈 연출, 게임별 차이를 관찰과 해석으로 나눠 적는다. 생성 이미지가 "AI 같다"·"서양 사람 같다"로 읽히는 흔한 원인도 조사한다. 결과는 `art/candidates/20261018/style-test/RESEARCH.md`에 출처와 함께 남기고, 원본 이미지를 복제·저장하지 않는다. 이 조사를 아래 시안의 근거로 쓴다.
1. **그림체 시안 먼저.** 전체를 다시 그리기 전에 2~3명(예: 세라·하린·라비엔)으로 서로 다른 그림체 방향 2~3안을 만들어 한 장의 비교판으로 보여 준다. 각 안마다 무엇을 바꿨는지(선, 채색, 얼굴 비례, 눈·코·입 표현, 피부·머리 질감, 조명)와 만든 방법을 적는다. 사용자가 안을 고르면 그 기준으로 전체를 다시 만든다.
2. **피드백의 해석은 Codex가 정한다.** "AI 같다", "자연스럽지 않다", "서양 사람 같다"가 현재 그림의 어떤 요소에서 오는지 관찰해 적고, 그것을 어떻게 바꿀지 제안한다. 기억 공방은 한국 서브컬처 수집형 RPG다(`art/requests/character-moments-20261018.md`의 방향은 그대로).
3. **유지할 것.** 캐릭터의 승인된 나이·정체성·의상 설계·소품·성격 축(§9.3.x)은 유지한다. 그림체(렌더링·얼굴 표현·비례·질감)를 바꾸는 요청이며 캐릭터를 다른 사람으로 바꾸는 요청이 아니다.
4. **방법.** 도구와 경로는 Codex가 고른다. 승인된 경로: Codex 구독 이미지 도구, 사용자 Windows ComfyUI의 SSH 호출(§13, `art/requests/local-comfy-20261017.md`), ImagineArt 무료 크레딧(§15). 유료 생성·API는 쓰지 않는다. 도구 한계로 원하는 그림체가 안 나오면 `real_constraint`로 적는다.
