# 환경 인수표 (v0.7) — 배포는 아직 수행하지 않음

| 환경 | DB·키·저장소 | 대상 | 결제 |
|---|---|---|---|
| local | 개발자 임시 DB(`tools/check_schema.sh`) | 단위·참조 시험 | mock만 |
| dev | 독립 프로젝트 + 합성 계정 | 팀·AI 에이전트 개발 | mock 네임스페이스 |
| staging | 독립 DB·발급자·저장소 | 통합·출시 후보 | Play 라이선스 테스터, 실제 검증 API |
| production | 운영 전용 자산 | 실사용자 | 실상품, 사람 승인 배포만 |

- Play 트랙과 서버 환경을 같은 것으로 보지 않는다. 클라이언트는 패키지명·서버 주소·토큰 발급자·상품 목록·콘텐츠 해시 조합을 시작 시 검사한다.
- AI 에이전트에 운영 권한·운영 데이터·비밀 키를 주지 않는다. 합성 데이터가 기본이다.
- 운영 서버는 시작 시와 요청마다 mock 결제·dev 인증을 거부한다.
- 이 파일은 실제 클라우드 구성을 만들지 않는다. 상세: `docs/design_v0.7.md` §18.
