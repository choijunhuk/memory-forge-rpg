# 실제 개발 — 서버 휴식·공방·상점 UI 연결

사용자 최신 지시: 개발은 공식 Claude Code Opus가 수행하고 Codex는 이미지 생성·지시·독립 검증·통합을 맡는다. 기존 Max 5x 구독 인증, 사용 크레딧 OFF, 자동 충전 OFF는 공식 계정 화면에서 새로 확인됐다. API·추가 결제·다른 모델·에이전트/CLI 재귀 호출 금지다. 이미지는 생성·수정하지 않는다.

이 작업은 계획이나 리뷰로 끝내지 말고 실제 UI 코드와 의미 있는 시험을 구현한다. 다른 작업자도 있으므로 아래 두 파일만 수정하고, 다른 변경을 되돌리지 않는다. 커밋·푸시·배포하지 않는다.

## 요구사항·역할·완료 기준

원본 v0.8.1의 탐사 노드 서비스와 현재 승인된 C# Run.Services/서버 명령을, 선택적 서버 연습 UI에서 이용할 수 있게 한다. 현재 MAP/BATTLE/REWARD 이후 미연결인 REST/FORGE/SHOP을 한 의미 있는 묶음으로 구현한다. 로컬 전체 원정은 유지한다. 원본 수치·가격·확률·카드·캐릭터·재화·영구 저장 의미를 변경하지 않는다.

먼저 CURRENT의 최신 서버 UI 상태, 해당 서비스 설계 절, `Run.Services.cs`, 서버 명령 디스패치/공개 상태 계약, 기존 클라이언트·시험의 필요한 부분만 확인한다. 전체 저장소·archive를 반복해서 읽지 않는다. 이미 코어에 있는 행동·검사·문구·전송 경로를 재사용한다.

1. REST의 실제 지원 선택과 제한, FORGE의 실제 지원 개조/대상 선택, SHOP의 공개 상품·가격·판매 상태를 기존 서버 전체 공개 상태와 현재 명령 계약대로 표시하고 실행한다. 임의의 수치·새 정책·샘플 상품을 만들지 않는다.
2. 기존 PracticeServerSession/outbox를 통해서만 명령을 보낸다. 대기 중 중복 클릭/중복 구매/다른 행동·불확실한 전송의 새 명령을 막고, 서버 승인·버전·소유자를 확인한 공개 상태로 화면을 갱신한다. 오류에서 일부 이득을 낙관적으로 남기지 않는다.
3. 자격·재료·수량 부족, 금지된 회복 등 서버 규칙을 유지한다. 대상 선택이 필요한 서비스는 선택 취소·노드 진행·재접속 후 오래된 선택을 재사용하지 않는다. 기존 battle/reward/input recovery를 유지한다.
4. 기존 서버 `proceed` 계약에 맞게 노드 종료와 다음 지도 이동을 제공한다. 사용 횟수/상품 정보는 공개 상태로 표시하고 작은 화면에서 모든 행에 접근할 수 있게 한다.
5. 실제 요구사항을 검증하는 NUnit/PlayMode 시험을 허용된 기존 시험 파일에 추가한다. 명령 페이로드/한 번만 전송/불확실 전송 잠금·실패 무변경/서버 승인 후 갱신 중 중요한 경계를 다룬다. 단순 구현 복사 시험으로 수를 늘리지 않는다.

현재 실행기는 Read/Glob/Grep/Edit만 허용하므로 설치·셸·Unity MCP 실행을 했다고 주장하지 않는다. 실행 제한은 구체적으로 결과에 남기고, 코드와 시험 구현을 계속한다. Codex가 도구 프로필과 독립 시험을 별도로 처리한다. 실제 하지 않은 검증은 NOT_RUN으로 표시한다.

결과는 변경한 동작, 원본 명세/서버 계약 근거, 수정 파일, 추가한 검증, 실행하지 못한 항목만 짧게 정리한다. 핵심 명세 불명확성이 발견되면 해당 동작만 보류하고 나머지 승인된 서비스를 구현한다.
