# P2-UNITY-MCP-BOOTSTRAP

요구사항: 설계 §16.4 Unity6LTS/URP2D·§14 화면·사용자 실제 UnityMCP 검증 지시.
역할: JS 참조 흐름과 C# 코어를 실제 Unity클라이언트에 연결하기 위한 기반. 전체 게임/전투 이식 완료가 아니다.
완료 기준: 공식 설치 Unity6.0.46f1에서 프로젝트 임포트, 무료 MIT MCP10.3.0 고정, 양 CLI 연결, 정확한 Editor 대상선택, 테스트 씬/Canvas/GameObject/Prefab을 MCP로생성·조회, Console/PlayMode/가능한시험 확인.
편집권: Codex단독, Claude읽기검토만. MCPasset_gen·외부AI API 금지, telemetryOFF, localhost전용. 기존 소스·데이터·설계·작업은 유지한다.
검증 전 연결/완성을 주장하지 않는다. 라이선스·실권한·실환경 막힘은 기록하고 독립 개발을 계속한다.
