# 사건·기록소 UI 독립 리뷰의 표현 보강

Codex가 새 선택/다중 카드·컨텍스트 폐기·서버 명령·원본 Core/로컬 UI와 비교했다. 구조/수치/명령 변경 없이 새 기능을 유지한다. 한 가지 기억 정책 안내를 보강한다. `ArchiveView`의 "패배하면 변경 1개만 남아요"를 원래 `SaveView`와 확정 정책처럼, **출발 전 기억은 유지되고 이번 탐사 변화는 파티 전체에서 1개까지 더해 저장한다**는 뜻이 분명하도록 짧게 고친다. 기존 기억 덱을 하나만 남기거나 무조건 최신 덱 전체를 덮어쓴다는 오해를 피한다. 기존 서버 수치/저장 규칙/Content는 바꾸지 않는다.

책임 파일은 `client/MemoryForgeUnity/Assets/Scripts/MemoryForgeServerPracticeClient.cs`뿐이다. 다른 변경은 보존한다. 이미지 작업·다른 AI 호출·커밋/푸시·과금 우회 금지. Opus5.5·기존 구독만 쓴다. 단순 UI 문구 수정이므로 범위를 넓히거나 새 테스트/추상화를 만들 필요 없다. Codex가 최신 두 UI 파일을 실제 Unity에서 재검증한다. 결과는 수정 문구와 미실행 항목만 짧게 보고한다.
