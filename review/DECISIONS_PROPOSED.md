# 검토 결정과 미적용 제안

기존 ADR-070~089는 원본 기록이다. 아래 `PATCHED`는 이번 로컬 인계 사본의 수정이며 상용 배포 승인을 의미하지 않는다.

| ID | 상태 | 내용 |
|---|---|---|
| AUD-101 | PATCHED | 첫 턴 방어·반격 보존. 이후 턴 초기화 유지 |
| AUD-102 | PATCHED | 유효한 진화 계열·성장치3·복제 계보 |
| AUD-103 | PATCHED | 실제 성장 이벤트에 이끼 후처리 통일 |
| AUD-104 | PATCHED | 저장 선택 입력 검증, _added 정리, 알 수 없는 적 행동 오류 |
| AUD-105 | REJECTED_CODE | 외부 before 덱 덧붙임 패치: 용량 초과와 복제 |
| AUD-106 | PROPOSED_NOT_INTEGRATED | 안정 개체 키 기반 패배 저장 v2 |
| AUD-107 | PROPOSED_NOT_APPLIED | 기억 용량 최대9를 승급으로 해금 |
| AUD-108 | PROPOSED_NOT_APPLIED | 균열1~3층 단일 파티 |
| AUD-109 | PROPOSED_NOT_APPLIED | 메인 결말을 본편 진행으로 완결, 수집은 외전 |
| AUD-110 | ART_BRIEF | 일률적 의상·동작·관계 제한 대신 개별 매력 브리프 |
| AUD-111 | PROPOSED_NOT_APPLIED | 성인6명 20~24세 대안. 미성년4명 나이 유지 |
| AUD-112 | ANALYSIS_ONLY | 110~120회/55%/배너 시점 비교. 가격·확률·수급은 원본 유지 |

데이터의 나이, 과금 확률, 재화량, 보스 보상, 성장 비용은 이번에 바꾸지 않았다. `proposals`는 생산 코드의 의존성이 아니다.
