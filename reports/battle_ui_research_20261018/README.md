# 전투 화면 UI/UX 조사와 재설계 제안 (2026-10-18)

사용자 판정: "ui ux가 진짜 너무 구린데… 배치가 조잡하고 전투하는 재미가 너무 없을 거 같아. 이런 류 게임들의 ui ux를 보고 와봐. 슬더슬도 보고." 앞선 두 번의 개편(377b080, 0782934)은 테두리·알약·보석 같은 겉모양만 바꿨고, 화면 구조는 여전히 글자 많은 대시보드였다.

## 조사 범위와 방법

- **직접 본 것:** Slay the Spire Steam 공식 스크린샷 2장(적 턴, 손패가 있는 내 턴).
- **조사 1 (덱빌딩 로그라이크):** Slay the Spire(커뮤니티 디컴파일 코드의 UI 수치 포함), Wildfrost, Monster Train, Balatro, Griftlands, Inscryption, Dicey Dungeons.
- **조사 2 (서브컬처 전투):** Limbus Company, Library of Ruina, Reverse: 1999, Blue Archive, 붕괴: 스타레일, Arknights, NIKKE, Epic Seven.
- 출처 링크는 아래 절마다 붙였다. 스크린샷 수치를 직접 잰 것은 StS뿐이고, 나머지 위치는 공개 자료 기반 추정이다. 원본 그림은 저장하지 않았다.

## 우리 화면이 구린 이유 (조사와 비교)

| 우리 화면(0782934) | 잘 만든 게임 |
|---|---|
| 적마다 큰 정보판(이름·체력·균열·약점·상태·이번/다음 의도 글)이 무대를 덮음 | 정보는 **몸 위에** 붙는다. 머리 위 의도 아이콘+숫자, 발밑 체력 막대, 그 아래 상태 아이콘(StS) |
| 의도를 "이번 공격 25 / 다음 기본 공격 14×2" 문장으로 씀 | **아이콘 + 숫자 하나**("12×3"), 피해량이 클수록 아이콘 단계가 커짐(StS 7단계) |
| 카드가 평평한 직사각형 5장을 나란히, 설명 글이 카드에 가득 | **부채꼴 손패**, 아래쪽이 화면 밖으로 잘림, 고르면 커지며 떠오름, 상세는 길게 누르기/호버 |
| 방식(즉시/다음 턴/다다음 턴)을 별도 버튼 줄로 고름 | **끌어서 놓는 곳**이 곧 선택(StS 드롭 존). 예약은 시간표 칸에 끌어 놓기 |
| 카드 사용 결과가 "행동 결과" 글 줄로 나옴 | 카드가 날아가 맞고, 캐릭터가 앞으로 나가고, 숫자가 튀고, 흔들림이 피해량에 비례(StS 3단계) |
| 기록 시간표·속도 버튼·행동 결과 줄이 화면 가운데를 가로지름 | 크롬은 **가장자리와 모서리**에만. 무대가 화면 높이의 55% 이상 |
| 필살기가 "충전 중" 버튼 | 초상 둘레 **게이지 링**, 가득 차면 금빛 맥동, 쓰면 컷인(스타레일·NIKKE·블루아카) |

## 공통 원리 (조사 결과)

1. 정보는 패널이 아니라 **캐릭터와 적 위에** 둔다(StS, Wildfrost).
2. 문장 대신 **아이콘 + 숫자**. 설명은 호버·길게 누르기(StS, Griftlands, 서브컬처 공통).
3. **무대가 화면의 대부분**, UI는 위 12%·아래 25%와 모서리(StS 상단 바 12%).
4. **결과 미리보기**: 카드를 끌 때 대상 체력 막대에 깎일 양을 유령 막대로(StS 독, Monster Train 처치 표시, Griftlands 해골).
5. **피드백은 크기에 비례**: 흔들림·숫자 크기·소리(StS, Balatro).
6. **다음 행동 안내**: 쓸 수 있는 카드에 빛, 다 쓰면 턴 종료 버튼 맥동(StS).
7. **미래를 공간으로**: 다음 턴 위협을 자리로 보여 준다(Inscryption 뒷줄, Wildfrost 카운터, StS2 의도 나란히).
8. 서브컬처 문법: **캐릭터가 곧 버튼**(초상 카드), 비스듬한 판·얇은 빛 테두리, 숫자는 보석 안, 필살기는 컷인·음성·히트스톱.

## 재설계 제안 — 전투 화면 (1600×900 기준)

- **위 12%:** 얇은 상단 바(층·동전·덱/기록/설정 아이콘). 지금의 큰 머리글·칩 묶음 제거.
- **무대 15–72%:** 왼쪽에 파티 3명(SD 크게, 대각선 배치), 오른쪽에 적(최대 3×2). 각 몸 위에 의도(이번: 큰 아이콘+숫자, 다음: 작고 흐린 아이콘), 발밑 체력 막대(방어는 막대 왼쪽 방패+숫자), 그 아래 상태 아이콘.
- **예약 레일:** 무대 위쪽 가운데의 얇은 띠 **지금 | 다음 | 다다음**. 예약된 카드는 작은 칩(효과 아이콘+숫자, 주인 색 테두리). 적의 다음 턴 의도도 같은 칸 아래에 보여 위협과 대응이 나란히 놓인다. 턴이 넘어가면 띠가 왼쪽으로 밀린다.
- **아래 25%:** 왼쪽 아래 행동력 보석, 가운데 부채꼴 손패(카드: 비용 보석, 주인 초상, 이름, 아이콘+숫자 한 줄), 오른쪽 아래 턴 종료 원판(지금 것 유지), 덱/버림 더미는 모서리 숫자 배지.
- **파티 초상(왼쪽 아래 손패 옆):** 3명 초상 + 체력 + 필살기 게이지 링. 가득 차면 금빛 맥동, 누르면 컷인.
- **카드 쓰기:** 카드를 위로 끌면 화살표가 대상까지 따라감. 적에게 놓으면 지금 사용, 레일의 '다음/다다음'에 놓으면 예약. 끄는 동안 대상 체력에 유령 피해, 레일에 미리보기. 탭-탭도 지원(휴대폰).
- **타격감:** 카드가 날아가 맞음 → 캐릭터 한 걸음 돌진 → 흰 번쩍임 → 테두리 있는 큰 피해 숫자 포물선 → 체력 막대 주황 잔상이 1.2초 뒤 줄어듦 → 흔들림 3단계(피해 5/20 기준). 내 턴/적 턴 배너.
- **숨기는 것(길게 누르기/호버):** 카드 규칙 글, 상태 설명, 적 스킬 이름과 정확한 수치, 덱·버림 목록, 행동 기록, 계산식.

화면 이름 규칙(온보딩·UiSkin이 찾는 `Enemy:<uid>`, `Hand:<uid>`, `EndTurn`, `Mode:*` 등)은 유지하거나 함께 옮긴다. 규칙·수치·카드 뜻은 바꾸지 않는다. 새로 필요한 그림(의도 아이콘 7단계, 카드 틀, 초상 크롭, 컷인 판)은 Codex에 요청한다.

## 조사 원문

### 조사 1 — Slay the Spire와 덱빌딩 로그라이크

(조사 담당 보고서를 그대로 옮김. 수치의 출처는 StS1 커뮤니티 디컴파일 [github.com/aeubanks/sts](https://github.com/aeubanks/sts)이며 비공식이다.)

- 상단 바 128px(12%), 바닥선 68.5%, 플레이어 x 25%, 적 x 75% 주변.
- 의도 아이콘 128px, 숫자 "12"/"12x3", 총 피해 5·10·15·20·25·30 단계별 7개 공격 아이콘([wiki](https://slaythespire.wiki.gg/wiki/Intent)).
- 체력 막대 20px, 방어는 막대 왼쪽 방패+숫자, 방어 중엔 막대가 파랗게.
- 에너지 구슬 x 10% y 82%, 턴 종료 x 85% y 81%, 뽑을/버린 더미는 아래 모서리 배지.
- 손패 0.75배(화면 너비 12%·높이 29%), 부채꼴, 아래가 화면 밖. 호버 시 1.0배로 커지고 이웃이 비켜남. 위로 끌면 드롭 존, 대상 카드는 빨간 곡선 화살표.
- 피해 숫자: 포물선, 빨강→흰색, 6배→1.2배. 흔들림: 5 미만 20px, 20 미만 50px, 20 이상 100px(0.3초). 체력 잔상 1.2초.
- Wildfrost 카운터([wiki](https://wildfrostwiki.com/Counter)), Monster Train 3층 레인과 처치 미리 표시([wiki](https://monster-train.fandom.com/wiki/Battle)), Balatro 단계별 점수 연출, Griftlands 치명 해골([wiki](https://griftlands.fandom.com/wiki/Battle)), Inscryption 뒷줄([wiki](https://inscryption.fandom.com/wiki/Card_Battle)).
