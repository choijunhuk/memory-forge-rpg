# 휴대폰 글자·안전 영역·공통 화면 보정

상태: **자동 시험·새 PC/APK 빌드 완료, 실제 실행 후속 수정·최신 CI 확인 중**. 휴대폰은 현재 ADB 목록에 없어 재연결을 요청했다. 새 APK는 읽기 전용 Android 에뮬레이터에서 설치·실행·JNI 교정·홈/동료/설정 탐색을 확인했다. 실제 PC는 연결 직후 네이티브 라이브러리 로딩에서 멈춰 인증 수용이 미완료다. 작은1280×720·130% 글자에서는 동료 카드 속성명과 홈 설명의 추가 배치 보정이 필요하다. **공식 Claude 최종 추가 재검토는 구독 세션 한도 때문에 미완료**이며 PR은 초안으로 유지한다. 사용자의 직전 시각 수용 거절을 기준으로 검증을 다시 시작했다.

## 변경과 단순화

- `MemoryForgeUiViewport.cs`와 로비·모집·성장·장비·지원·주간 화면은 실제 화면 픽셀/안전 영역으로 HUD를 배치하고 본문/주 제어14sp, 제목18sp, 메타데이터12sp를 적용한다. BestFit 축소 대신 실측 행 높이·간격·스크롤을 사용한다.
- 인물과 모먼트의 기존1600×900 무대는 원본 비율을 유지한다. 배경은 원본 비율을 유지하는 cover이며 안전 영역 밖까지 그림과 차광이 이어진다.
- 내부 탐사 UI의 절대 좌표 계약을 복원하고, 바깥 손패·턴 종료·버림 표시는 같은 오른쪽 기준을 사용한다. 실제 카드 탭이 턴 종료로 전달되던 충돌을 해결했다. 턴 수는 상단에 유지하고, 하단 문구와 버림 수치의 실제 glyph가 겹치지 않게 분리했다. 보석의 행동력 숫자는 유지하고 중복 하단 설명만 제거했다.
- 페이지를 다시 나눌 때 원문·공백·줄바꿈·읽은 prefix·타이핑 위치를 보존한다. 기존 타이핑/탭 루프와 글자 실측 도우미를 재사용하며, 완료 대사의 재등장·같은 프레임 탭 누락·화자/▼ 잘림을 수정했다. beat·음성·연출·기존 대기 시간을 다시 실행하지 않는다.
- 재배치 뒤 대표 이름/설명·계정 연결·모달 입력 차단을 유지한다. 출격 준비는 기존 패널 빌더를 재사용하여 파괴한 객체를 다시 쓰던 경로를 없앴다. 설정 창의 PC 화면 모드 행과 장면 목록 재배치, 출격 상태 문구 앞8단위 간격을 보완했다.
- 실제 Android 빌드에서 확인된 JNI 타입 누락은 설치된 Unity 내장 `com.unity.modules.androidjni@1.0.0` 활성화로 해결했다. 외부/전이 의존성은 없다. Android 저장·native fd 구현은 변경하지 않았다.

가격·확률·재화·Core·서버·창작 원본은 변경하지 않았다. 공식 Opus가 대사 재배치를 구현했고 Codex가 공통 UI·통합·회귀 수정을 맡았다.

## 독립 검토와 남은 경계

공식 Opus Max의 첫 Gamma 검토는 FAIL3P1/4P2였고, 두 번째 검토는 기존7건/LOW2건의 해결을 확인한 뒤 새1P1/2P2를 찾았다. 세 새 문제는 실제 RED→수정→GREEN을 기록했다. 별도 대사 수정은 공식 Opus 검토 PASS다. 최종 추가 검토 호출은 세션 한도(process1,05:20KST 초기화 안내)로 종료하여 **PASS로 세지 않는다**. 독립 Codex 보충 검토는 최종 소스/시험/내장 JNI 설정에 P1/P2가 없다고 판정했으나, 반대 AI 최종 재검토를 대신하지 않는다. 통합 PR은 초안이다.

계정은 기존 revision352·모집 내역·재화를 보존하며, 레이아웃 수용을 위해 추가 모집이나 성장/장비/지원/전투 명령을 보내지 않는다. 시간에 따라 바뀌는 집중 표시와 저장 파일 변경을 구분한다. 인증 키·실제 계정 원장·원시 영수증·기기 캡처는 비공개 로컬 증거에만 둔다.

전용 캐릭터 그림 일부와 상용 계정/결제·운영 배포는 별도 범위다. 자동 합성 화면과 실제 기기·사용자 최종 시각 판정은 각각 표시한다.
