# 폰 안전 영역·글자·공통 재배치 보정

사용자가 지적한 좌우 잘림과 읽기 어려운 글자를 실제 안전 영역과 글자 배율로 재현하여 고쳤다. 기존1600×900 창작 무대를 유지하면서 HUD·스크롤·입력 위치를 현재 화면에 맞춘다. 게임 규칙·서버·가격·확률·창작 원본은 이번 UI 보정에서 변경하지 않았다.

## 변경과 단순화

- 홈의 중복 설명 두 개를 덜고, 설정/종료와 출격 정보 사이 간격을 확보했다. 동료 이름·속성과 미보유 동료 상세 안내는 글자 실측으로 배치한다.
- 모든 화면의 실제 안전 영역·14/18/12sp 글자 역할과48dp 입력을 유지한다. 기존 `WholeText`, 스크롤, 앵커 도우미를 재사용한다. BestFit 축소·새 의존성·새 레이아웃 계층은 없다.
- 손패가 턴 종료로 전달되던 입력 충돌, 적별 체력 예측, 대사 재배치 중 읽은 부분/탭/화자 표시, 모달 입력, PC 설정 행을 보정했다. 원문·beat·성장/전투 결과는 유지한다.
- 뽑을/버림/소멸 숫자와 행동력은 실제 glyph 경계로 분리한다. 소멸 숫자는 행동력 아래에 표시하고 그림자·폭을 확보했다. 테스트는 분리된 표시용 상태만 그리며 실제 Run과 전송을 변경하지 않는다.
- 성장 카드·필살기 글자는 테두리 모서리 안에 배치한다. 공통 필살기 제목 아래 이름·정확한 게이지를 두 줄로 표시하고, 글자 크기를 유지한 채 줄 간격과 실측 행 높이를 맞춘다. 테두리는 실제 부모에 붙여 넓은 화면의 이중 확장을 없앴다.
- Android JNI는 설치된 Unity 내장 모듈 활성화다. macOS Mono의 계정 연결 정지는 [별도 저장 수정](../mobile_native_storage_20261023/README.md)으로 커밋했다. 저장 잠금·0600·요청 ID/본문 재시도는 유지한다.

이번 후속 변경 파일은 `MemoryForgeLobbyClient`, `MemoryForgeGrowthClient`, `MemoryForgeExpeditionClient`, 두 AP 관측 시험과 두 모바일 회귀 시험이다. 앞선 공통 UI17개 파일 변경은 `bada9d1`, 네이티브 저장 변경은 `d03648b`에 있다. Unity가 만든 설정/메타 변경6개는 별도 보관 후 복원했고 `.utmp`와 원래 작업 폴더의 변경/아트는 건드리지 않았다.

## 실제 모집·저장과 남은 경계

보관된351 전체 저장의 격리 사본으로 실제 네이티브 PC UI 모집1회와 앱 재시작·재인증 후 같은 최근 결과를 확인했다. 사본은 티켓6→5·누적23→24·결정900/유료0이고, 기존351 영수증과 원장8개는 정확히 유지됐으며 새 영수증/원장1개만 추가됐다. 전체352 영수증 verifier PASS, 검사 전후 바이트·수정 시각도 같다. Final3 PC는 같은 최근 결과·잔액·성장 화면을 읽기 전용으로 재확인했으며 저장 바이트/수정 시각이 같았다. 최신 화면 검사에서 추가 모집·성장·장비·전투 명령은0회다. 실제100/100 네이티브 상태와 Android 인증 성장/모집은 미실행이며 합성 전체 게이지 검사와 구분한다.

원래 임시 DEV 서버 프로세스와 임시 fixture/저장/인증 파일은 사라졌다. 과거 실제352의 검증 이력과 응답/체크섬은 있지만 전체 파일은 없고351 원본 백업만 보관돼 있다. 누락된 마지막 모집을 다시 보내면 새 난수를 쓰므로 정확한 복구가 아니다. **사본의 새352를 과거 실제352 복구로 보고하지 않는다.** 원본 백업·기존 접속 정보는 덮어쓰지 않았다.

실제 Android 익명 화면과 인증된 성장/모집, 에디터 합성 시험과 물리 폰 수용은 각각 구분한다. 이전 Android에서 강제로 실행 중 해상도/밀도를 바꾼 때의 Unity InputSystem 오류2건은 별도 이력이며, 정상 cold boot와 글자 배율 전환은 오류0건이었다. Windows/Linux Unity 플레이어, 폰 최종 시각 판정, 일부 전용 그림·밸런스2단계·상용 인증/결제/운영 배포는 이번 완료 주장에 포함하지 않는다.
