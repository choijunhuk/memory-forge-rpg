# 탐사 복귀와 공방·동료·출격 준비 개편

기준: 2026-10-21, `58ab499` 다음 작업 단위. 사용자가 휴대폰 작업을 제외하고, 탐사 포기 뒤 다음 탐사만 요구하는 흐름과 홈·동료·출격 화면 전반의 빈 배치를 지적했다.

## 변경

- 포기 확인은 실제로 공방으로 돌아간다. 종료 결과의 주 행동은 공방 복귀이고, 바로 다음 탐사 출발은 보조 선택이다. 취소·중복 입력·씬 로드 실패도 처리한다.
- 단순 씬 이동에서 사라지던 연습 기억 저장소 전체(덱·버전·이력·영수증)와 출발/요청 번호를 앱 세션 안에서 이어 준다. 홈 자체는 새 Run을 만들지 않는다. 재출격 실패 때는 기억과 선택 길이를 보관하고 명시적 재시도만 허용한다.
- 홈은 캐릭터 중심 배경에 실제 목적지·연습 파티·도감/모집 동선을 정렬했다. 동료 화면은3열 도감과 실제 능력 미리보기, 준비 화면은 목적지·길이·실제3인 정보를 보여 준다.144 터치 설정에서도 상세 탭·푸터·헤더와 선택 버튼이 겹치지 않는다.
- 대표 동료와 탐사 길이를 복귀 후 유지하고 결과를 한 번 알린다. 결과 카드의 승리 통계·기억 덱을 명확히 표시한다. 큰 빈 덱 열은 실제 카드 수에 맞췄다.
- 기존 컴포넌트·디자인 토큰·원본 그림과 고정 연습 규칙을 재사용했다. 새 패키지, 가짜 소유/퀘스트/성장 보상이나 새 경제 규칙은 넣지 않았다.
