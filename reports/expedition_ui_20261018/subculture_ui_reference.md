# 서브컬처 모바일 게임 UI/UX 참고 노트 (2026-10-18)

사용자 지적: "웹사이트 게임 같다, 모바일 게임이 아니다". 실제 화면을 보고 공통 문법을 정리했다. 다른 게임의 화면·그림을 가져오지 않는다. 배치·정보 위계·조작 관례만 참고한다.

## 공통 문법

### 전투
1. **화면 = 무대.** 아군은 왼쪽, 적은 오른쪽에 크게 선다. 체력·상태는 정보 패널이 아니라 **유닛 바로 위·아래의 작은 막대와 아이콘**이다. 사각 정보 상자를 무대 위에 깔지 않는다.
2. **적 의도는 머리 위 기호 + 숫자 하나.** 카제나는 마름모 안 숫자(남은 턴/위력)와 작은 상태 아이콘 한 줄이다. 자세한 설명은 길게 누르거나 대상으로 고르면 뜬다.
3. **공용 체력은 왼쪽 위 한 줄.** 큰 막대에 숫자, 방어는 방패 아이콘+숫자, 그 아래 파티 초상 띠.
4. **손패는 하단 중앙 부채꼴.** 카드는 거의 전부 그림이고, 위쪽 띠에 비용 숫자, 이름, 종류 글자가 있다. 테두리 색이 등급·속성을 말한다. 효과 글은 카드에 길게 쓰지 않고, 고르거나 길게 누를 때 확대 카드로 보여 준다. 카드 위에 주인 얼굴 아이콘이 작게 붙는다.
5. **행동력은 큰 숫자 하나.** 손패 가운데 아래에 빛나는 숫자로 둔다. 글자로 "행동력"을 쓰지 않는다.
6. **덱·버림은 가장자리 카드 더미 아이콘 + 장수.** 왼쪽은 뽑을 더미, 오른쪽은 버림 더미다.
7. **턴 종료는 오른쪽 아래 큰 원형 버튼.** 체크·화살표 기호로 표시하고, 할 일이 끝나면 빛난다.
8. **필살기·게이지는 가장자리 세로 띠.** 초상 + 비용 숫자 + 막대로 둔다(카제나 왼쪽 EP 패널, 림버스 하단 콘솔).
9. **오른쪽 위 작은 아이콘 버튼.** 자동·배속·메뉴를 둔다. 기록·덱 보기는 메뉴 안이나 아이콘으로 넣는다.
10. **대상 지정은 곡선 화살표 + 적 발밑 고리.** 고른 카드는 커지며 떠오른다.
11. **글자 대신 기호.** 상태·약점·의도·자원이 모두 아이콘+숫자다. 문장은 툴팁·확대 카드·기록에만 있다.

### 지도·장소·보상
1. **노드는 상자가 아니라 그림 메달·알약.** 원형·타원 안에 장소 그림, 테두리 링에 상태(완료 체크, 현재 빛) 표시, 이름은 작은 리본.
2. **선택 상세는 오른쪽 서랍.** 머리 그림, 설명, 보상 아이콘 줄, 큰 알약 버튼 "진입".
3. **상점·식당 등 장소는 인물이 맞이한다.** 왼쪽에 NPC(또는 동료) 전신과 말풍선 한 줄을 둔다. 오른쪽은 테마 틀(종이·황동 장식) 안의 품목 타일이다. 타일은 아이콘 그림 + 이름 + 가격 칩이다.
4. **보상 카드 고르기는 무대 연출.** 흐린 배경 위에 큰 카드 3장을 두고, 고른 카드는 금빛 테두리로 빛나며 떠오른다.
5. **상단 바는 왼쪽 뒤로가기 + 화면 이름, 오른쪽 재화·홈·메뉴.** 화면마다 같은 자리다.

### 시각 언어
- 패널은 **반투명 유리 + 얇은 장식 테두리**(모서리 장식, 이중선)다. 두꺼운 남색 박스를 빼곡히 늘어놓지 않는다.
- **알약·원형·마름모** 모양을 많이 쓴다. 직사각 버튼만 쓰지 않는다.
- 숫자는 굵은 외곽선 글꼴로 크게 쓰고, 설명은 작게 쓴다. 정보는 위계로 나눈다.
- 움직임:
  - 카드는 뽑을 때 펼쳐지고, 쓸 때 날아간다.
  - 피격 숫자가 튄다.
  - 버튼은 누르면 들어간다.
  - 화면 전환은 쓸어 넘긴다.
  - 필살기는 전면 컷인이다.

## Memory Forge에 옮길 것 (다음 패스)

규칙·문구 뜻·숫자는 그대로 두고, 보이는 방식만 바꾼다. 시험이 의존하는 이름은 유지한다.

| 지금 | 다음 |
|---|---|
| 상단 "파티 체력 …" 패널 + 턴·방어·반격 문장 줄 | 왼쪽 위 공용 체력 막대(숫자 큼) + 방어·반격·부채·잔향 아이콘 칩. 턴은 작은 배지 |
| 왼쪽 파티 패널(사각) | 무대 왼쪽에 SD 3명이 서고 발밑에 게이지. 필살기는 왼쪽 가장자리 세로 띠(초상+게이지, 준비되면 빛남) |
| 적마다 사각 정보 상자 | 적 그림을 무대에 크게 세운다. 머리 위에 체력 막대·균열 칸·의도(시계 문양 배지 + 숫자 + "이번/다음" 작은 글)를 둔다. 약점·상태는 아이콘이다. 전체 문구는 적을 길게 누르거나 선택했을 때 뜨는 툴팁에 담는다(기존 문구 그대로) |
| 시간표 칸 줄(글자) | 손패 위 작은 시계 문자판 슬롯 아이콘(다음·다다음). 칸을 누르면 카드 이름이 뜬다 |
| 행동 결과 줄 + 속도 버튼 4개 | 오른쪽 위 아이콘 버튼(배속·동작 줄이기·건너뛰기). 결과는 무대 위 숫자와 짧은 띠 |
| 카드 행동 줄(방식 버튼 3개 + 확정) | 카드를 고르면 그 카드가 확대된다. 그 옆에 즉시/다음/다다음 원형 버튼과 확정 버튼이 붙는 문맥 메뉴로 바꾼다 |
| 손패(평평한 상자 줄) | 하단 부채꼴 카드: 큰 그림 창, 비용 보석, 이름판, 테두리 색, 주인 얼굴 아이콘 |
| 행동력 칩 | 손패 가운데 아래 큰 보석 숫자 |
| 턴 종료(사각) | 오른쪽 아래 큰 원형 황동 버튼(시계 바늘 기호) |
| 지도 사각 칸 | 원형 메달 노드(그림 + 링), 리본 이름, 오른쪽 서랍 상세 |
| 장소 화면 아이콘 카드 | 동료(또는 장소 인물) 전신 + 말풍선, 오른쪽 장식 틀 품목 타일 |
| 보상 | 흐린 배경 위 큰 카드 3장, 고르면 빛나며 떠오름 |

### Codex에 맡길 원본 (이미지 제작은 Codex 담당)
UI 스킨 키트를 Memory Forge 세계관(멈춘 자정의 시계 도시, 황동·잉크·청록 기억빛)에 맞게, 9-slice 가능한 원본으로 요청한다.

- 카드 틀: 공용/캐릭터, 속성 4색 테두리.
- 비용 보석, 이름판, 행동력 보석, 턴 종료 원형 버튼, 필살기 초상 틀.
- 의도 배지(시계 문양), 패널 테두리(모서리 장식), 리본, 알약 버튼, 지도 메달 틀.

키트가 오기 전에는 코드로 만든 임시 모양(원·알약·그라데이션·빛)으로 배치와 연출을 먼저 맞춘다.
