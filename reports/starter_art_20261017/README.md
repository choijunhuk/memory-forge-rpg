# 로컬 이미지 생성 경로와 첫 3인 아트셋 검증

## 결과

- Mac의 `~/.config/aiimg/aiimg.zsh`와 `~/.zshrc`에 `aiimg "프롬프트"`를 설치했다. 원래 `.zshrc`는 별도 백업했다. 새 TTY zsh에서 함수가 로드됨을 확인했다.
- 사용자가 제공한 Windows ED25519 지문을 실제 조회 결과와 대조했고 일치했다. 전용 known-hosts 파일과 `StrictHostKeyChecking=yes`, `GlobalKnownHostsFile=/dev/null`로 SSH 로그인했다. 개인키·비밀번호를 만들거나 복사하지 않았다.
- 실제 ComfyUI 생성물: `~/Downloads/ai-20261017-124815.png`, PNG RGB 768×768, 615,922 bytes, SHA256 `282c3380575323828dfc5e5aa5913cda92a6d60097f5670ff56ca0e6f18e9d2b`. PNG 서명·모든 청크 CRC·실제 디코딩·크기를 확인했고 Preview 실행이 성공했다.
- Windows 생성 명령과 PNG 워크플로를 읽어 로컬 FLUX.2 Klein 4B / Qwen 텍스트 인코더 / VAE 경로임을 확인했다. 원격 명령은 stderr에 상태를, stdout에 PNG만 보낸다. 브라우저·scp·새 유료 API를 사용하지 않았다.
- 원격 예약 작업은 읽기 전용 조회에서 ComfyUI·OpenWebUI 모두 `Disabled`임을 확인했다. 해당 작업을 활성화하거나 수정하지 않았다.
- ComfyUI 첫 시안은 서명 무기·눈 표현이 명세에 미달해 미채택했다. Codex 내장 이미지 도구로 세라·하린·니아의 시트·컷인·투명 SD 9장을 제작하고, 원본·수정본·프롬프트·참조·SHA256을 보존했다.

## 구현·독립 검사

`tools/ai/aiimg.zsh`는 프롬프트를 셸 명령에 삽입하지 않고 stdin으로 전송한다. 전송 성공·실제 PNG 확인 후 `os.link`로 완성 파일을 게시해 기존 파일·디렉터리·심볼릭 링크를 덮어쓰지 않는다. 실패·신호 종료의 자체 임시 파일은 trap으로 정리한다. Preview를 열지 못해도 완성된 PNG는 보존한다. Python3는 이미 설치된 표준 라이브러리만 사용한다.

`tools/ai/check_aiimg.zsh`의 독립 검사는 인용부호·명령 치환·한글의 리터럴 stdin, 전용 신뢰 옵션, PNG 확인, Preview 인자, 파일/디렉터리/심볼릭 링크 충돌, 생성 실패·잘못된 PNG·빈 프롬프트 정리를 검증했다. 실제 네트워크 생성과 구분되는 대역 검사다. GPT-6.1 Sol 독립 검토가 찾은 디렉터리 대상 `ln` 문제와 시스템 known-hosts 혼용을 수정하고, 같은 두 문제의 재검토에서 해결됨을 확인했다.

## 실제 Unity 결과

Unity 6000.0.46f1의 기존 MCP를 복구해 `MemoryForgeUnity@4034a4e2fe236d6e`에 연결했다. 새 후보 9장만 임포트하고 새 `MemoryForgeArtReview.unity` 씬을 실제 Editor API로 만들었다. 기존 전투 씬·빌드 씬 목록·런타임 스크립트는 바꾸지 않았다.

씬 생성 도구의 독립 Codex 검토에서 비활성 additive 씬의 미저장 변경 보호와 전역 자산 저장 문제를 찾아 수정했다. 모든 열린 씬을 먼저 확인하고, 기존 검수 씬도 임포트 전에 보호하며, 전역 `SaveAssets` 호출을 제거했다. 선택된 새 텍스처와 새 검수 씬만 명시적으로 저장한다. 실제 미저장 비활성 additive 씬을 만든 뒤 전체 생성 도구를 호출해 거절·기존 씬 보존을 확인했고, 도구가 만든 임시 시험 씬만 정리했다. 두 수정의 독립 재검토도 통과했다.

실제 GUI Editor(`isBatch=false`) Play Mode에서 RawImage 9개 모두에 텍스처가 할당되었고, 원본 크기 유지와 투명 SD를 확인했다. 축소 샘플링을 수정한 전후 화면 및 MCP 응답을 이 경로에 보관한다. 게임 코드 오류는 없었고, Metal의 `Ignoring depth surface load/store action as it is memoryless` 경고 2건은 별도로 기록했다. 이것은 검수 씬 표시 확인이며 실제 전투에 일러스트를 연결한 플레이 수용 검사는 아니다.

- 원본 배포 매니페스트는 재생성하지 않았다. 기존 누적 변경과 이번 provenance 추가를 원본 무결성 PASS로 바꾸지 않는다.

## 남은 범위와 협업 한계

9장은 개발 후보이며 10명 전체 이미지셋·최종 2048×1024 시트 마스터·PSD·리그·애니메이션·고유 카드별 일러스트 완성을 뜻하지 않는다.

Claude 아트 교차 리뷰는 미실행이다. 공식 CLI의 구독 인증과 현재 Usage credits OFF는 확인했으나 실행기가 요구하는 최신 전체 청구 증거가 만료되어 추가 추론을 보류했다. CLI 상태 확인 중 PTY 표준입력 오류로 의도치 않은 요청 1회가 시작되어 중단했다. 이를 코드/아트 리뷰 성공으로 세지 않는다. 상세 실행 세션과 청구 상태 자료는 비공개 로컬 기록에만 둔다. 이번 추가 Codex 독립 검토를 Claude 리뷰라고 보고하지 않는다.
