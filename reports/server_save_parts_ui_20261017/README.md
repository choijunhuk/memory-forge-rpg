## 구현·독립 검토

- 보유 부품은 ID별 수량과 회로/각인을 표시한다. 알 수 없거나 저장에 맞지 않는 부품은 이유를 표시하며 비활성화한다. 부품을 고르면 공개 덱의 모든 비무기 대상이 별도 스크롤에 나타난다.
- 부품 선택/취소는 미전송이고 현재 기억 선택·미리보기를 유지한다. 대상 카드를 누르면 기존 서버 명령을 보내기 전에 선택·미리보기·창을 폐기한다. 서버 재조회 전 수량/카드 mods/기억을 낙관적으로 변경하지 않는다.
- 같은 칸 교체·1개 소모·무환급·영구 기억은 후속 변화 선택/저장이 필요함을 안내한다. 비용·변화·합법성은 계산하지 않고 서버의 새 목록/미리보기를 쓴다.
- 다른 모달·저장·변화 선택과 상호 배제하며 새 문맥/새로고침/이탈 때 미전송 부품 선택을 버린다. 불확실한 응답은 기존 outbox의 동일 요청으로만 복구한다. 동일 ID 두 복사본을 전역 한 번으로 막지 않으며, 대기 중 연타/오래된 버튼만 차단한다.
