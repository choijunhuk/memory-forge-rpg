# 전투 화면 무대 중심 재배치 (2026-10-18)

사용자 판정: "ui ux가 진짜 너무 구린데… 배치가 조잡하고 전투하는 재미가 너무 없을거 같아." 조사와 제안은 `reports/battle_ui_research_20261018/`(README, `mockup_battle.png`)에 있고, 이 폴더는 그 제안을 실제 Unity 화면에 옮긴 결과다. 이전 화면은 `reports/expedition_restyle_20261018/after/battle_*.png`.

## 무엇이 바뀌었나

| 자리 | 전 | 후 |
|---|---|---|
| 적 정보 | 적 옆에 큰 정보판(이름·체력·균열·약점·상태·의도 글) | **머리 위 의도**(Codex 의도 아이콘 + 이번/다음 글), **발밑 이름판**(이름, 체력 막대 위 숫자, 방패, 균열 눈금, 약점, 상태) |
| 파티 | 초상 열 + "필살기/충전 중" 버튼 | SD 3명이 **대각선**으로 무대에 섬. **캐릭터 자체가 필살기 버튼**, 가득 차면 금빛 "필살기" 알약. 발밑에 공유 체력 막대와 방패·반격·부채·잔향·버프 |
| 예약 | 화면 가운데를 가로지르는 시간표 | 위쪽 가운데 얇은 **예약 레일**(다음 턴·다다음 턴, Codex 레일 칸) |
| 행동 결과·속도 | 가운데 줄 | 레일 아래 얇은 띠, 속도·건너뛰기는 띠 오른쪽 |
| 손패 | 평평한 직사각형 줄 | **부채꼴**(바깥 카드가 기울고 낮아짐), 고른 카드는 똑바로 떠오름, Codex 카드 테두리·비용 보석 |
| 카드 쓰기 | 카드 → 방식 버튼 → 확정 | 그대로 + **끌어서 쓰기**: 적에게 놓으면 바로, 레일의 다음 턴/다다음 턴에 놓으면 예약. 끄는 동안 화살표, 놓을 자리 빛, Core 예상 글, 대상 체력에서 깎일 양(흰 막대) |
| 행동력·턴 종료 | 상단 판의 글자, 원판 | 왼쪽 아래 **결정 보석**(Codex), 오른쪽 아래 Codex 턴 종료 원판(눌림·비활성 그림 교체) |
| 타격감 | 숫자 + 짧은 흔들림 | 피해 크기 단계(5·20)에 따라 흔들림·숫자 크기, 숫자 튀어나옴, 흰 폭발 + Codex 베기 6프레임, 20 이상이면 배경도 흔들림, 체력 잔상이 잠깐 머문 뒤 줄어듦, 쓴 캐릭터가 한 걸음 돌진, 전투 시작·내 턴 띠(Codex 띠 그림) |

규칙·수치·카드 뜻은 바꾸지 않았다. 끌어서 쓰기(`DragPlay`)는 누르기 경로와 같은 `SelectCard`/`SelectEnemy`/`SelectMode`/`ConfirmCard`를 거친다. 동작 줄이기에서는 새 연출(띠, 폭발, 튀어나옴, 베기, 잔상, 돌진)이 모두 즉시 멈춘다.

## Codex UI 키트

`art/ui/battle-kit/`(Codex 제작, 105개 투명 PNG, `README.md`에 자리·크기·9-slice). `client/MemoryForgeUnity/Assets/Resources/Art/UI/battle/`에 바이트 그대로 복사했다(`tools/check_art_copies.py`). 9-slice 조각(레일, 체력 틀, 카드 테두리, 알약, 판)은 키트 지침대로 밉맵 없이 bilinear·clamp, 작게 줄여 쓰는 아이콘은 밉맵 유지(`Assets/Editor/MemoryForgeArtImport.cs`). 그림이 없으면 코드 모양이 그 자리를 지킨다.

이번에 쓴 것: 의도 19종(공격 7단계는 보이는 총 피해 5 단위), 방패, 체력 틀 2종, 레일 칸, 행동력 보석, 비용 보석, 턴 종료 3상태, 카드 테두리 5종, 끌기 화살표, 턴 띠 2종, 베기 6프레임. 아직 안 쓴 것: 상태 아이콘 10종, 초상 고리, 컷인 판, 알약 버튼, 지도 메달, 더미 아이콘.

## 독립 검토 (Codex, 읽기 전용)

1차: 높음 2·중간 5. 체력 그림이 채움을 가림, 무대 밖 놓기도 사용됨, 끌기 뒤 클릭도 발생, 휴대폰 머리 줄 누르는 영역과 레일 스크롤 겹침, 부채꼴 카드 글 잘림, 오른쪽 버튼 끌기, 끄는 동안 예상 없음. 모두 고쳤다(체력 틀을 뒤로 보내고 채움은 틀 안쪽 칸, 놓기는 무대 안만, `eligibleForClick` 끔, 레일은 스크롤 없이 칸이 좁아짐, 손패 칸을 화면 끝까지 늘리고 카드 높이에 기울기 여유, 왼쪽 버튼만, Core 예상 표시). 2차: 여섯 개 FIXED, 끌기 체력 미리보기가 Core의 전체 적 합계(`EnemyHpLoss`)를 한 적의 막대에 그리는 새 결함 1건(중간). 흰 막대는 살아 있는 적이 하나일 때만 그리게 고쳤다(글은 Core 예상 그대로). 3차: **APPROVE**, 새 결함 없음. 원문은 이 폴더 `codex_review_1.txt`~`codex_review_3.txt`.

## 보류·다음

- 사용자 판정 필요: 실제 플레이 감각(끌기 손맛, 연출 속도), 휴대폰 실기기.
- 무대 비율: 데스크톱 무대가 화면 높이의 약 42%다. 위쪽(머리 줄·레일·행동 결과 띠)이 아직 192단위를 쓴다. 행동 결과 띠는 기존 시험이 대기 중에도 보이게 요구한다.
- 제안 중 미구현: 레일의 "지금" 칸과 적의 다음 위협을 레일에 나란히 보이기, 초상 둘레 필살기 고리, 필살기 컷인, 상태 아이콘 칩, 길게 누르기 상세.
- 적이 여럿일 때 적마다 깎일 체력 미리보기: Core 예상에 적별 손실 칸이 필요하다(지금은 합계만 있다).
- 의도는 아이콘 + 글 두 줄이다. 시험이 정확한 "이번 …\n다음 …" 글을 요구해서 숫자만 남기지 않았다.
