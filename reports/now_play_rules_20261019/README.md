## 1. 규칙 (엔진 두 개를 같은 동작으로)

- **카드 사용:** 모든 카드는 지금만 쓴다. 예약 방식·칸·장부·앞당김·봉인은 플레이어가 만들 수 없다.
- **턴 종료:** 손패는 버린다. `보존` 카드(키워드 `retain` 또는 부품 `retain`)만 손에 남고 「보존했던 카드」(`held`)가 된다.
  - `held`는 카드를 쓰거나, 뽑거나, 회수하거나, 효과로 버리거나 소멸할 때 지워진다.
- **성장:** 예약 해결 때가 아니라 해결될 때마다 붙는다.
- **데이터:** 예약 수치(`rv`·`ra`·`rn`) 105곳을 지웠다.
  - 다시 설계한 것: 카드 8장, 부품 4개, 유물 6개, 무기 패시브 2개, 세라의 패시브·필살기·공명 r1·r6, 절제·담보 계약, 기록 균열 규칙 `rift_reserve`.
  - 세라는 「보존한 큰 한 발」 저격수가 됐다. 시한 포격과 종언의 초침에 보존이 붙었다.
- **두 엔진의 일치:** JS 기준 엔진(`engine/rules-core.js`)과 C# Core(`core/MemoryForge.Core`)를 같은 동작으로 맞췄다.
  - 모든 교차 언어 벡터를 다시 만들었다.
  - CoreChecks 17개 모음이 모두 JS 벡터와 일치한다.
- **2단계로 남긴 것:**
  - 도달할 수 없게 된 예약 코드(장부·칸 계산·`pull`·`slot`·적 `sealSlot`·`delayRes`의 예약 경로)의 삭제.
  - 균형 재조정.

## 2. 전투 화면 정리

- 예약 시간표를 지웠다. 무대가 위로 올라왔다.
- 사용 방식 버튼(지금·다음 턴·다다음 턴)과 「방식 선택」 단계를 지웠다. 카드를 고르면 바로 확정할 수 있다.
- 늘 떠 있던 사용법 줄을 지웠다. 첫 실행 안내가 가르친다.
- 행동 결과 줄과 속도·건너뛰기 버튼은 행동 연출 중에만 나온다.
- 카드 줄은 카드를 골랐을 때만 나온다. 예상, 카드→대상, 카드 설명, 확정만 남겼다.
- 전투 중 머리줄의 로고를 지웠다. 장소와 더미 수(뽑을·버림, 소멸은 있을 때만)만 작게 보인다. 동전은 전투에서 감췄다.
- 파티:
  - 게이지 숫자 글자를 지우고 링만 남겼다.
  - 잔향 칩은 리엔이 있을 때만 나온다.
- 손패:
  - 「즉시 · 예약」 표시 대신 「보존」 칩을 단다.
  - 보존했던 카드는 「보존 중」과 황동 빛으로 구분한다.
- 첫 실행 안내:
  - 방식 단계와 예약 강의를 지웠다.
  - 2강을 「보존」으로, 보스 강의를 「보존해 둔 큰 카드를 균열 때」로 바꿨다.

## 3. 홈 화면

게임은 홈에서 시작한다.

| 영역 | 내용 |
|---|---|
| 위쪽 줄 | 기억 공방, 지금 동료의 이름, 설정, 종료(PC) |
| 출격 | 큰 타일. 「출격 준비」 창을 연다 |
| 동료 · 인연 · 연출 | 바로 쓸 수 있는 타일 |
| 기억 덱 · 스토리 · 도전 · 모집 | 「준비 중」으로 흐리게. 누를 수 없다(설계 §14.7: 미연결 기능을 완료처럼 보이지 않게) |
| 출격 준비 | 1구역 지도, 탐사 길이(짧은 탐사·1구역 / 긴 탐사·2구역까지), 파티(세라·하린·니아) 미리보기, 출발 |
| 설정 | 움직임 줄이기. PC에서는 창 모드·전체 화면 전환도 있다 |

동료의 모먼트 장면은 그대로 재생된다. 장면이 나오는 동안 홈의 조작 요소는 물러난다.

### 사람 판정이 필요한 것

- **필살기가 드물다.** 탐욕 봇 30판 기준으로 필살기가 찬 전투는 20%→15.5%, 필살기 사용은 211→134회로 줄었다. 안내를 따른 짧은 탐사(seed 1234, 6전투)에서는 한 번도 차지 않았다.
  - 원인: 게이지는 전투마다 0에서 시작한다. 카드 1장 +10, 한 턴 상한 30이다. 그런데 전투가 짧아졌다(6.9→5.4턴).
  - 안내 3강의 필살기 단계는 보스 강의를 막지 않게 바꿨다.
  - 수치(게이지·카드당 획득)는 설계 수치라 바꾸지 않았다. 서브컬처 전투의 핵심 연출이라 조정을 권한다.
