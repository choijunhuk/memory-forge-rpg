## 남은 범위

실제 초기 승리 사례, 이미 이전 버그로 멈춘 저장의 복구, 신뢰 snapshot 복원, 미저작 데이터의 원자적 진입, 전체 C# Run·서버/계정·Android/실기기·전체 탐사 UI는 완료하지 않았다. 없는 보스 설정은 기존처럼 위치/층/RNG 일부를 바꾼 뒤 실패할 수 있으므로 전체 롤백 성공으로 보고하지 않는다. HTML의 시작 즉시 패배는 기존 저장 화면으로 이동하며 상세 원인 요약은 후속 UI 범위다.

Unity 전투 연습의 실제26Play/3Edit·스크린샷·새 Mac 빌드는 [앞선 검증](../unity_client_20261015/)에 해당한다. 이 단위는 C#나 Unity 자산을 바꾸지 않았으므로 해당 결과를 새 C# 탐사 수용으로 재분류하지 않는다. AndroidPlayer 모듈은 설치돼 있지 않다. 다음 작업인 R1 실제 C# 탐사 명령과 전체 상태 오라클을 계속 진행한다.
