# P1 후반 적 행동·동일 조건 측정 — 2026-10-15

구현·자동 검증은 통과했다. **밸런스 목표는 미달**이며 후반 적은 시험 전용 후보로 유지한다. 기존 설계 본문·게임 수치·라이브 데이터는 변경하지 않았다.

## 구현과 경계

- JS Battle: 시간 착취, 칸 봉인, 시간 지연, 침묵, 이름 먹기, 실제 무명 2페이즈.
- HTML: 의도·착취/부채 구분·현재 의도 기준 예상 AP·지연 시 버림/환급 없음 사전 안내·예약 원래 위력·페이즈 상세·로그.
- 칸 봉인은 턴 t의 적 단계에서 다음 플레이어 턴 t+1의 다음 칸(만기 t+2)을 사용한다. 현재 턴 임시 칸은 만료되므로 제외한다. 현재 턴에 만료되는 봉인이나 곧 해결될 예약은 새 봉인을 막지 않는다.
- 시간 지연은 최신 order의 예약에 due +1만 적용한다. kind/위력은 그대로이며 넘친 예약은 버린 더미로, 이미 지불한 AP는 환급하지 않는다. 플레이어 앞당김의 기존 위력 감소 규칙은 유지한다.
- 침묵 +1은 중첩하지 않으며 무료 사본·다음 카드 무료가 우선한다. 다음 플레이어 턴 종료 후 풀린다.
- 이름 먹기는 discard 토큰 우선·기존 소멸 훅·재현 RNG를 사용한다. 대상 없으면 RNG를 쓰지 않는다.
- 첫 보스 HP 0에서는 초과 피해 이월 없이 상태/방어/균열을 초기화하고 같은 UID로 2페이즈를 연다. 다음 다단 타격은 이어지며 처치 훅은 최종 사망 때만 실행한다. 반격으로 전환하면 이전 몸의 적 다단 공격은 중단한다.
- 원문 23종과 외부 검토의 조우 그룹은 proposals/late_enemies.cjs overlay로만 사용한다. 라이브 적은 20종 그대로이고 authored 플래그는 바꾸지 않았다.

## 협업·보존

공식 Claude Code CLI 2.1.285를 claude.ai Max 구독 인증·Usage credits OFF 확인 후 직접 호출했다. UI 작업과 읽기 전용 교차 검토는 각각 실제 session_id와 exit 0을 기록한다. Claude는 명령 실행 권한이 없어 자체 시험은 NOT_RUN이며 위 시험은 Codex가 통합 후 실행했다. Codex 포함 사용량 잔여와 자동 충전 OFF를 확인했고 구매 크레딧 잔액은 후검사에서 변하지 않았다. API/추가 크레딧/종량제/자동 충전·토큰 추출·--bare는 사용하지 않았다. 계정 식별자·원시 CLI 출력은 ops/ai/local의 Git 제외 경로에만 둔다. 이미지 작업은 수행하지 않았다.

Claude 검토에서 봉인 만기 기준, 예고 AP 착취 누락, 지연 전 버림·환급 안내, 측정 세부 근거 공백을 확인했다. 회귀 시험을 먼저 실패시킨 뒤 수정했고 최종 원시 지표 전체를 보존했다. 소스 범위 재검토에서도 재현 가능한 차단 결함은 발견하지 못했다.

## 남은 범위

후반 목표 밸런스·스토리 4~6장·연출 준비·사람 플레이 검사, 무료 용량/업적/패스/무기 전승의 미결정 사항은 완료로 표시하지 않는다. C# Battle/Run 전체·서버/DB 동시성·Unity/Android 실기기·실결제·운영 배포는 이번 검증 범위 밖이다. CI의 기존 C# 유틸리티/스키마 검사는 이 기능의 전체 이식·서버 구현 증거가 아니다. AP·지연 미리보기는 현재 상태/의도 기준이며 이후 피해나 적 행동 순서 변화 전체를 예측하지 않는다.
