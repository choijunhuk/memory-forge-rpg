# PC 한 판 완주 확인 (2026-10-17)

## 목적

모바일보다 먼저, PC(Unity)에서 한 판을 처음부터 끝까지 실제 UI로 진행할 수 있는지 확인한다. 이어서 더블클릭으로 실행되는 macOS 빌드를 만든다. 대상은 오프라인 로컬 연습판 `Assets/Scenes/MemoryForgeExpedition.unity`(빌드 첫 씬)이다.

## Editor 완주 (실제 uGUI 입력 경로)

- **방법:** 루트 세션이 Editor 잠금을 잡은 상태에서 Play 모드로 들어갔다. Editor 업데이트 루프에서 도는 드라이버가 화면에 보이는 버튼만 골라 눌렀다.
  - 클릭은 EventSystem 레이캐스트로 넣었다. 맨 위에 맞은 그래픽이 그 버튼이 아니면 "가려짐"으로 기록한다.
  - 버튼은 화면이 다시 그려진 뒤에만 눌렀다.
  - 판단은 단순 규칙이다: 갈 수 있는 첫 칸 → 카드는 순서대로 즉시 사용, 적 대상은 첫 적 → 보상은 첫 카드·유물 → 휴식은 회복 → 공방·상점은 떠나기.
- **Unity 백그라운드 처리:** Unity가 백그라운드일 때 Game 뷰가 다시 그려지지 않아 새 버튼이 레이캐스트에 잡히지 않았다. 런타임에서만 `Application.runInBackground = true`로 바꿨다. 프로젝트 설정은 바꾸지 않았다.
- **결과:** 짧은 탐사 1구역을 완주했다.
  - 전투 6회(엘리트 1, 보스 포함), 처치 11
  - 공방 2회, 전투 보상(카드·유물·부품)
  - 종료 기억 저장 → "탐사 완주"와 다음 탐사 출발 화면
  - 클릭 459회, 가려진 버튼 0, 진행 막힘 0
  - 남은 체력 112/243
  - Console 오류 0. 경고 2건은 예전부터 있던 Metal depth-surface 경고다.
- **드라이버 한계 (게임 결함 아님):**
  - 예약 전용 카드(`시한 포격`)는 `즉시`만 시도해서 쓰지 못했다.
  - 행동력이 모자란 카드는 "못 씀"으로 넘겼다.
  - 종료 기억 저장은 변화를 고르지 않고 "기존 덱 유지"로 눌렀다.
  - 사람 플레이였다면 변화를 골랐을 것이다.

## macOS 빌드

- **빌드:** `ops/ai/local/builds/MemoryForge-PC-20261017.app`(Git 제외). StandaloneOSX, 릴리스 옵션, 빌드 설정의 활성 씬 3개. 결과 Succeeded, 오류 0, 경고 0, 113.9MB, 19.6초.
- **실행:** 창 모드 1600×900으로 실행했다. Player 로그에 오류·예외 0. 지도 화면이 정상 표시됐다(`06_macos_build_launch.png`).
- **보정:** 창 제목이 템플릿 이름 `2D_URP`로 나와 `PlayerSettings.productName`을 `Memory Forge`로 바꿨다.
  - 코드에서 제품 이름이나 `persistentDataPath`를 쓰는 곳은 없다.
  - 로그 경로는 `~/Library/Logs/DefaultCompany/Memory Forge/`로 바뀐다.
  - 저장할 때 Unity가 빈 값 뒤에 공백을 붙이는 직렬화 차이가 생겼다. 그 차이는 되돌리고 이 한 줄만 남겼다.

## 사람 플레이 관점의 다음 과제 (관찰)

- **화면:** 캐릭터·적 그림이 없는 텍스트 위주 UI다. 전투 화면에 정보가 많아 처음 하는 사람에게는 안내가 필요하다.
- **저장:** 로컬 연습판은 앱을 닫으면 진행이 사라진다(화면에 명시돼 있음).
- **회사 정보:** 회사 이름과 번들 ID는 아직 템플릿 값(`DefaultCompany`, `com.DefaultCompany.2D-URP`)이다. 배포 전에 정한다.
- **남은 확인:** 실제 사람이 처음부터 직접 플레이하는 시험(사람 플레이 10판)은 아직 하지 않았다.
