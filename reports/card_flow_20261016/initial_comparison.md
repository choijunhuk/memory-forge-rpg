시간 예약(다음/다다음 턴 슬롯), 미전송 입력 의도, 서버 확인 대기, 승인 후 연출 대기는 별개의 상태다. 현재 로컬 연습 명령을 서버 ACK로 표시하지 않는다. 향후 미응답 명령은 request ID·버전으로 멱등 처리하며 원본Core의 검증/원자성을 유지한다.

바로 도입하지 않을 것: 퓨즈/AP3/경직 보상/피니셔/되돌리기/대상재지정/리셔플·RNG 교체, 클라이언트 선확정 서버 대체, 연산 오류의 일부 이득 보존 후 정상 진행. CF01의 턴 종료 정리/반응 순서 불일치와 CF02/03의 명시된 정책 위험은 구별한다.

첫 구현 후보는 (1) 기존 UI의 낡은 콜백·선택 유효성·복귀 재구성 보강, (2) 기존 승인 이벤트를 소비하는 작은 연출/미전송 의도 경계다. 상대AI의 독립 검토 후 확정하고, 현행 UI의 held-press/선택 무소비/확정1회 회귀를 유지한다. 실제 Unity와 헤드리스·기기·서버 검증은 각각 기록한다.
