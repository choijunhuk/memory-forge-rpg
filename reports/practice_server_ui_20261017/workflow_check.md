# 작업 속도·사용량 점검

사용자가 반복 교차검증과 토큰 낭비를 지적했다. 실제 산출물·호출 기록·실행 증거로 확인했다.

- 전송 초안 한 호출은18분 관측 시점까지 읽기/검색30회였다. 코드가 실제 작성됐지만 넓은 문맥과 작업 분할에도 비용이 들었다. CLI의 누적 캐시 읽기를 새 토큰 소모나 구독 차감으로 환산하지 않는다.
- 확인된 전송 결함3개와 테스트를 한 High 호출로 묶었다. 새 UI도 하나의 기능으로 작성하고 독립 검토·Editor 실행을 병행했다. 실제 실패한 입력 게이트만 좁게 수정·재검토했다.
- 통과한 검사를 새 변경 없이 반복하지 않는다. 최종 UI에서는 변경된 입력 경계, 실제HTTP/복귀/지도 흐름과 전체Unity 회귀를 확인했다. 일반 UI/구체 수정은 High, 복잡한 전송은xhigh, 중요한 독립 검토는 검증된SolMax를 사용했다. Medium/다른모델/추가과금은 사용하지 않았다.
- 조회 시 Codex의 제공된 주간 구간은62% 사용/38% 잔여, ordinaryUsageAllowed=true였다. 이 값은 계정 전체이고 이 작업만의 정확한 토큰 비중이나 비용을 뜻하지 않는다. 구매 크레딧 사용 승인은 하지 않았다.

구현과 검증은 source/commit, 실제 .NET·Unity·HTTP 결과, 원격CI로 구분한다. 이번 UI는 네트워크 게임 전체 완료가 아니다.
